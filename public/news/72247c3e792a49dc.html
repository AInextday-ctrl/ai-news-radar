Meituan releases a 1.6-trillion-parameter agent model that never touched an Nvidia GPU

📖 Read Original Source Report ↗
Meituan's LongCat team has released the LongCat-2.5 model, a Mixture-of-Experts (MoE) model with 1.6 trillion total parameters and approximately 48 billion active parameters per token. The model was trained entirely on domestic hardware without Nvidia GPUs, utilizing 4-bit quantization, and supports a million-token context window with multimodal capabilities.

  • [Core Event] Meituan LongCat Development Team: Released a 1.6-trillion-parameter MoE model, LongCat-2.5, featuring multimodal support and 4-bit quantization for domestic chips
  • [Root Cause & Mechanism] Building a sovereign AI agent infrastructure to execute complex multi-step tasks and long-context reasoning
  • [Key Metrics] Utilizes MoE architecture with 1.6T total and 48B active parameters.
  • [Key Position & Outlook] Features a 1M-token context window and specialized agent training in sandboxed environments.

🤖 AI Radar Technical Deep-Dive

The core significance of this model lies in validating that competitive performance can be achieved without Nvidia GPUs by leveraging MoE architecture and hardware-software co-optimization. This achievement signals that domestic AI clusters have bridged the technical gap from experimental to commercial-grade for complex agent tasks, significantly bolstering the case for supply chain independence in the Chinese cloud and AI infrastructure market.

📰 Full In-Depth Coverage

THE DECODER Full Report

Meituan releases the weights for LongCat-2.5, a 1.6-trillion-parameter model built for AI agents. It was trained entirely on Chinese hardware and performs at the level US models like Claude Opus 5 reached a few months ago on coding benchmarks.

The LongCat team at Chinese food delivery company Meituan has released the weights for LongCat-2.5, one week after the model's official unveiling. LongCat-2.5 is built for agents that work through long, multi-step tasks autonomously, particularly coding. According to Meituan, it comes close to top Western models on several benchmarks.

LongCat-2.5 is a mixture-of-experts model that activates only a subset of its specialized subnetworks for each token it processes. Out of 1.6 trillion total parameters, roughly 48 billion are active per token. Through the API, the model handles up to one million tokens at once and generates responses up to 128,000 tokens long. It understands text, images, and video, responds in text, and lets users toggle reasoning on and off.

LongCat-2.5 converts images into tokens

LongCat-2.5 builds on its predecessor LongCat-2.0 and adds image understanding. Many multimodal models bolt on a separate image encoder after the fact. LongCat-2.5 instead converts images into tokens that the model processes alongside text, as is standard practice for today's LLMs. The approach draws on the research model LongCat-Next and aims to improve visual coding, design, and 3D tasks.

[caption id="attachment_42886" align="alignnone" width="1800"] LongCat-2.5 breaks images down at their native resolution into discrete tokens that the model processes alongside text. | Image: Meituan[/caption]

For reinforcement learning, the team used real software tasks from GitHub pull requests along with recreated agent failures. To make sure the model actually solved the tasks during training, the developers blocked internet access in the training environments, removed Git history and cached files, and had a language model check its solutions for tricks. The team also distilled the capabilities of several specialized teacher models for agent work, reasoning, and dialog into LongCat-2.5.

[caption id="attachment_42885" align="alignnone" width="1200"] Meituan generates training tasks from real GitHub repositories and blocks shortcuts like web search and Git history in the sandbox. | Image: Meituan[/caption]

Meituan quantizes the experts' weights and activations to 4-bit precision, which Chinese chips can process natively. In Meituan's load tests, throughput rises 43.3 percent for prompt processing and 42.77 percent for response generation compared with an 8-bit version. Meituan says accuracy stays on par with the uncompressed model.

This version is available in a separate repository. The self-hosting guide describes a cluster of 194 Huawei Ascend accelerators from the Atlas A2 series. Two handle image processing, 64 handle prompt ingestion, and 128 handle response generation. There's no guidance for Nvidia GPUs.

LongCat-2.5 trails Opus 5 slightly on terminal tasks

The LongCat team reports 88.4 points on Terminal Bench v2.1, a benchmark that measures how well agents solve command-line tasks. Meituan lists Claude Opus 5 at 89.1, GPT-5.6 Sol at 88.8, and Deepseek-V4.1-Flash at the top of the table with 90.6.

DeepSWE tests how well models fix bugs in real code repositories. Here LongCat-2.5 jumps from 9.7 to 64.6 points, placing it behind every other model in the table except Claude Opus 4.8, with Deepseek-V4.1-Flash leading at 74.2 and GPT-5.6 Sol at 72.7. The more recent Claude Opus 5.5 and GPT-6.1 Sol are not included in the table.

[caption id="attachment_42887" align="alignnone" width="1800"] In Meituan's own evaluation, LongCat-2.5 improves substantially over its predecessor and comes close to Claude Opus 5 and GPT-5.6 Sol on several agent benchmarks. | Image: Meituan[/caption]

Terminal Bench v4.0, the harder variant, puts LongCat-2.5 at 38.5 points, slightly above GPT-5.6 Sol's 37.3 but well below Opus 5's 53.9. The model posts 91.9 on the web search benchmark BrowseComp, the highest score in the table, though Meituan ran this test in its own environment.

The weights are available under the MIT license, which allows commercial use, modification, and redistribution. Users can also try LongCat-2.5 in a chat interface at https://longcat.ai/. Its API supports both the OpenAI and Anthropic formats and plugs into agent harnesses like Claude Code, Codex, and Hermes. At launch, Meituan is charging a limited-time promotional price equivalent to roughly €0.27 per million input tokens and €1.07 per million output tokens.

Meituan says it trained the predecessor LongCat-2.0 in late June entirely on a cluster of more than 50,000 Chinese AI chips. Before that, the model ran anonymously as "Owl Alpha" on OpenRouter. Chinese open-weight models like Kimi K3.1 and GLM-5.3 have largely caught up with top US models on common benchmarks.

Open-weight models optimized for Chinese chips from the start make that hardware more attractive outside China too. Beyond multimodal agent models, Meituan is also working on image generators. The company previously released LongCat-Image, an open-source text-to-image model that gets by with just 6 billion parameters and prioritizes efficiency over sheer model size.

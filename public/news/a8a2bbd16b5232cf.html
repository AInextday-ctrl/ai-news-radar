Google warns that fully automated cyberattacks have arrived and will get worse fast

✍️ By THE DECODER

Google's Threat Intelligence Group (GTIG) has identified the first fully autonomous attack system, 'exploit_agent,' which leverages LLMs to identify vulnerabilities, develop exploits, and execute them without human intervention. While these attacks currently leave forensic traces, the transition to end-to-end automated exploitation marks a critical turning point in AI-driven cybersecurity warfare.

⚡ Executive Summary & Key Facts

  • [Core Event] Google Threat Intelligence Group (GTIG): Detected 'exploit_agent' framework for autonomous vulnerability exploitation
  • [Root Cause & Mechanism] Attackers aiming to minimize the time gap between patch analysis and exploit deployment
  • [Key Technical Spec] Discovery of 'exploit_agent' autonomous attack framework.
  • [Key Position & Outlook] High-speed, large-scale attacks with visible forensic trails.

🤖 AI Radar Technical Deep-Dive

Attackers are industrializing cyberattacks through LLMs, necessitating a shift in defense from signature-based detection to semantic behavioral analysis. Organizations must now integrate AI-driven defense models directly into CI/CD pipelines to counter these asymmetric, high-speed automated threats.

📰 In-Depth Coverage (Excerpt)

THE DECODER Full Report

Google's Threat Intelligence Group (GTIG) says it has observed attackers fully automating vulnerability discovery and exploitation for the first time, with no human in the loop. GTIG found an exposed server running an AI framework called "exploit_agent" that connects to multiple language models, according to the GTIG AI Threat Tracker. The system compares software code before and after patches, identifies vulnerabilities, develops exploits, and runs them automatically. Russian-language comments in the configuration files suggest the operator speaks Russian.

Server data suggests the operator targeted French websites in media, entertainment, and education. GTIG calls the shift a critical turning point but says these automated attacks currently sacrifice stealth for speed, leaving forensic traces that make them easier to detect...

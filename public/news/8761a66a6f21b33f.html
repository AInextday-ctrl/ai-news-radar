It forces developers to restructure AI workflows while reinforcing Apple's centralized control over ecosystem compliance, pushing AI deployments toward stricter privacy sandboxes.

📰 In-Depth Coverage (Excerpt)

MacRumors Full Report

With the latest macOS 27.3 beta, Apple is giving Mac users more control over the data they share and the access they give to apps, including apps that use AI agents. Apple today informed developers about upcoming changes to the Full Disk Access API and the Device Control and Data Access API.

Apple says developers will need to adjust user onboarding and make sure apps can "gracefully handle" access to a limited set of folders or apps when using the APIs being overhauled.

Apps that use Full Disk Access for disk backup or the new Accessibility settings for assistive technologies can request entitlements to offer the same experience for new installations that they offered before macOS 27.3.

Right now, known apps keep their current experience without an entitlement, and app permissions granted by users prior to macOS 27.3 will remain in effect. Mac users will see these changes when approving new app permission requests, and entitlement details are coming soon.

Last month, Apple said it would add "additional controls" for Full Disk Access on Macs because of the risks posed by AI agents. Apple warned that some developers are using Full Disk Access in ways that can put users at risk, exposing files, mail, messages, browsing history, and more...

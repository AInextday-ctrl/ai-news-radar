OpenAI推出GPT-6系列医疗自动化智能体

✍️ 记者 / 供稿: Alan Truly

OpenAI推出GPT-6 Astra与Luna模型，旨在通过自动操作UI处理医疗行政与保险文书

⚡ 核心要点提炼与关键事实

  • 【核心事件】OpenAI在医疗机构行政与保险审核系统：发布GPT-6 Astra与Luna模型，通过API自动处理病历数据与医疗保险预授权申请
  • 【起因与机理】针对医疗行业API匮乏的现状，降低人工行政处理成本并提升临床效率
  • 【关键数据与实测】在Stanford HealthAdminBench测试中模型准确率高达94.3%，且成本大幅降低。
  • 【各方立场与态度】已与CVS Health等机构合作，主要应用于病历转录、保险预授权与医疗预约处理。

📰 深度报道原文实录

THE DECODER 权威实录

OpenAI 希望 GPT-6 Astra 和 GPT-6 Luna 作为数字文员通过诊所软件和保险门户进行点击和打字。据该公司称，GPT-6 Luna 处理管理任务的费用约为每项任务 8.5 美分。

在最近的产品公告中，OpenAI 针对医疗保健领域缺乏 API 的问题。九月下旬，计算机使用的代理集成到代理 API 中，以人类的方式操作现有的用户界面。在这种情况下，他们在电子健康记录和外部门户网站之间传输数据。

根据 OpenAI 的说法，当患者报告背痛时，代理将搜索相关的先前发现并起草 MRI 命令和对患者的答复。它还应该在保险公司的门户网站上准备一份事先授权请求。临床医生和负责的行政人员在发布这些草案之前会对其进行审查。这些功能可通过 API 以及 ChatGPT for Healthcare 和 ChatGPT for Clinicians 中使用。

GPT-6 Luna 完成管理任务，每项任务 8.5 美分

在 OpenAI 描述的一项评估中，GPT-6 Astra 完成了电子健康记录收件箱中的任务，其中包括为手臂骨折的儿童准备布洛芬剂量。医生评审员将 325 项评估任务中的 99% 评为临床安全。在 646 条评论中，93% 的评论者认为准备工作非常或极其有帮助。

对于事先授权、上诉或医疗设备订单等管理工作流程，OpenAI 参考了斯坦福大学研究人员的独立 HealthAdminBench 基准。 GPT-6 Astra 获得了 94.3% 的得分。 GPT-6 Luna 专为低 API 定价而打造，得分为 91.8%，根据 OpenAI 的数据，每个任务的成本约为 8.5 美分，比 Astra 低 98%。两种模型都在基准测试中以最大推理努力运行。

美国主要医疗保健公司测试并部署 OpenAI 的计算机使用代理

一些合作伙伴组织正在帮助推进这项技术。在 CVS Health，代理已经跨不同的系统处理转诊和专家咨询。公告称，一名工作人员在一个周末清理了长达数月积压的外发文件，另一名工作人员每天处理数万次咨询的系统步骤。 CVS Health 在 GitHub 上发布了其软件架构作为 Agent Kit。

在保险公司 Cigna Healthcare，这些模型合并了来自 10 多个独立系统的患者信息。 Abridge 正在开发用于临床出院计划的药物。 Ambience 已经展示了额外的安全机制，当患者的记录不清楚时，代理会停止并询问医生输入信息。像 Assort 这样的初创公司也使用 Codex 中的功能来完成实践管理软件中的推荐，但其 API 不支持最终点击。

数据隐私、健康记录和欧洲

由于代理直接在电子健康记录中工作，因此保护敏感的健康数据是一个核心问题。 OpenAI 表示，它不会使用组织数据来训练其基础模型。据该公司称，ChatGPT for Healthcare 提供基于角色的访问控制和审核日志。组织还可以配置应用程序和环境，以便代理仅访问给定任务所需的记录和操作。

对于具有受保护健康信息的符合 HIPAA 的工作流程，组织必须与 OpenAI 签署业务合作协议 (BAA)。他们还需要使用涵盖的服务并应用所需的安全和保留设置。医疗机构本身有责任正确使用，但 OpenAI 作为缔约方，也有 HIPAA 规定的自己的义务。在美国使用 ChatGPT for Clinicians（一项免费的个人计划）的经过验证的医疗专业人员也可以签署 BAA，尽管它仅适用于协议涵盖的功能。

据 OpenAI 称，在 CVS Health 部署中，数据保留在 CVS 控制的基础设施内。 CVS 通过屏幕截图和操作日志来审查代理的工作步骤。该公告没有说明这些屏幕截图的处理位置或存储时间。它也没有涉及欧洲通用数据保护条例（GDPR）。到目前为止，该产品的目标市场是美国市场。

OpenAI 将该技术主要定位为在高度分散的医疗保健系统中应对行政摩擦的工具。是否会被广泛采用并不仅仅取决于该公司公告中引用的准确率和成本。同样具有决定性意义的是代理与现有系统的连接有多可靠，以及人工智能代理在实践中是否可以得到可靠的监控。另一个悬而未决的问题是，是否需要人类决定临床或法律相关的步骤。

🤖 雷达专属 AI 研判与技术透视

医疗行业的自动化瓶颈在于高度碎片化的遗留系统与缺乏开放API，OpenAI的Agent-to-UI路径绕过了传统IT改造难度，直接通过视觉模拟人类操作，是LLM从生成式辅助向执行式生产力转化的关键节点。这一技术路线将显著降低保险审核与医院行政运维成本，但也对现有的数据合规性审查机制提出了更严峻的合规与信任挑战。

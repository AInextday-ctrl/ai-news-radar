Anthropic通过AI自动化实现模型跨硬件高效迁移

✍️ 记者 / 供稿: Shane Downing

Anthropic联合创始人Tom Brown透露，利用Claude Mythos Preview技术，AI模型在AMD GPU上的适配部署时间从数月压缩至三天，且几乎无需人工干预

⚡ 核心要点提炼与关键事实

  • 【核心事件】Anthropic联合创始人兼首席算力官Tom Brown在投资者简报会议：通过AI驱动的自动代码生成缩短硬件适配周期，构建异构算力池
  • 【起因与机理】降低对CUDA生态的依赖，提升数据中心硬件部署效率与采购决策灵活性
  • 【关键数据与实测】将适配周期从6-12个月压缩至3天，无需深度人工干预。
  • 【各方立场与态度】建立跨平台硬件适配策略，增强对单一算力供应方的议价能力。

Tom's Hardware 权威实录

Anthropic 告诉 IPO 投资者，其 Claude Mythos Preview 模型在大约三天内完成了使其人工智能在 AMD GPU 上运行所需的软件工作，“基本上没有人工干预”，据称这项工作过去需要 6 到 12 个月的时间。这三天的内容是在 AMD MI355X GPU 上“以有用的性能水平”快速处理一个 Anthropic 模型，并通过 Mythos 移植或编写“几乎 100% 的内核”。这种将人工智能模型与一家公司的芯片联系起来的低级代码长期以来一直是 Nvidia CUDA 护城河的一部分，而能够在几天内编写出来的人工智能则表明护城河正在被侵蚀。

Anthropic 的联合创始人兼首席计算官汤姆·布朗 (Tom Brown) 进行了时间比较，他向投资者指出，最初意味着使用一个由“数十名工程师”组成的团队。该公司已经在多种芯片上运行其模型——Nvidia 和 AMD 的 GPU、谷歌的 TPU 和 AWS Trainium——并且其机群作为“一个可替代的计算池”进行管理。布朗称早期的多芯片决策是“一次非常规的赌注”。这可能是明智之举，因为谷歌的 TPU 现在可以本地运行 PyTorch 中构建的 AI 模型，并且 Meta 在生产中使用它们。

Anthropic 声称，这项工作过去需要 6 到 12 个月的时间，这来自过去的工作，来自其“使用传统工程方法开发新加速器的历史经验”，其中为每个硬件平台定制代码是一项挑战。消除这一入门障碍可能会减少购买决策的难度，Anthropic 今年首次开始与 AMD GPU 合作，目前已达成高达 2 吉瓦的协议。

CUDA 是 Nvidia 的编程平台，已有近二十年的历史，非常成熟。 AMD 有一个等效的 ROCm，以 HIP 作为其编程层。为 CUDA 编写的代码必须进行转换才能在那里工作，AMD 甚至为此过程构建了一个名为 HIPify 的工具。转换仍然存在转换成本，AMD 人工智能软件副总裁 Anush Elangovan 在 4 月份告诉《EE Times》，“Claude 比 HIPify 更好，因为它内置了网络搜索。”

自去年 8 月以来，AMD 一直在论证人工智能可以编写此类代码，并推出了当时达不到人类专家水平的研究代理。同年 9 月，AMD 首席执行官苏姿丰 (Lisa Su) 在Possible 播客上表示，大部分人工智能软件都是用 CUDA 编写的，需要“翻译成 AMD”，并且“现在很多工作都可以用软件来完成”。

今年 7 月初，AMD 人工智能高级副总裁 Vamsi Boppana 表示，其工程师正在使用人工智能模型生成 GPU 内核，Su 表示，当她询问她的团队是否正在帮助 Anthropic 工程师开发 MI355X 时，她被告知他们不需要任何帮助。 Boppana 表示，在某些情况下，生成的内核甚至“比大多数手动调整的版本更好”。根据 7 月份与 Anthropic 达成的协议，AMD 还使用 Claude 来优化其 Instinct GPU 的工作负载并加速 ROCm 开发。

在 7 月份的 AMD 高级人工智能活动中，OpenAI 的 Philippe Tillet 表示，一旦 OpenAI 拿到了 Helios 机架，一名工程师就在几天内确认一切正常，并且“从某种意义上说，代理正在接管我们的工作，就像内核工程师一样。”活动之前，AMD 公司副总裁兼公司数据中心 GPU 业务总经理 Andrew Dieckman 告诉记者，他与 AMD 客户关于 CUDA 的对话几乎为零。

不过，直到本周，所有这些都来自 AMD 或其舞台，而不是来自 Anthropic 自己的投资者。 Anthropic 购买芯片而不是出售它们，而且该公司将于下周进行 IPO，因此其多芯片方法（现在至少有一些数据支持）比芯片制造商的声明更有分量。它的招股说明书也以书面形式表示，尽管没有具体数字：“我们可以用以前所用时间的一小部分来安装新的芯片平台。”

工作负载的提示处理（预填充）部分是模型在开始回复之前读取并处理所给内容的步骤，Anthropic 没有透露是否也包括回复步骤（解码）。 Anthropic 的图表的轴标记为“搭载新芯片的时间”，显示两条线都达到了相同的“~100%”标记，但没有说明 100% 是什么。该公司还没有透露该模型在 AMD 的 GPU 上与 Nvidia 的 GPU 上运行的速度有多快，这就是我们希望看到的比较，以显示运行人工智能编写的代码的 AMD 芯片是否可以与 Nvidia 的芯片相媲美。

另一方面，Nvidia 首席执行官黄仁勋在 4 月份接受 Dwarkesh Patel 采访时表示，Nvidia 已经在自己的内核上使用了人工智能，并且最了解自己的芯片——“没有人比我们更了解我们的架构”——并且可以充分利用它们。当被问及为什么像 Anthropic 这样的实验室使用其他加速器时，他称 Anthropic 是“一个独特的实例，而不是一种趋势”。 Nvidia 和 AMD 等七家公司正在以 IPO 价格购买 260 亿美元的 Anthropic 股票，因此 Nvidia 投资的正是黄黄所说的例外公司。

7 月下旬，SemiAnalysis 发表了一篇文章“AMD 能否打破 CUDA 护城河？”，该文章本质上是说，软件创建与一年前的护城河已经不一样了。也就是说，AMD 的问题在于，通过代理编码，“每个代理都需要 GPU 来测试其代码”，这意味着编写代码的人工智能仍然需要硬件。它发现AMD内部一直缺乏用于此类开发的GPU，这阻碍了AMD的发展，并可能成为新的瓶颈。

这使得 CUDA 的护城河介于两者之间。让模型在新芯片上运行，曾经是昂贵的部件，现在似乎变得越来越便宜，而更好的人工智能可能会削弱英伟达“最了解自己的硬件”的说法。至于 Anthropic 的可替代池，其中的芯片并不是完全可互换的——例如，谷歌的 TPU 越来越专业化——并且要充分利用其中任何一个仍然需要对硬件进行测试。护城河正在变窄，但并没有消失。

Anthropic 的首款 AMD MI450 芯片预计将于 2027 年上半年在 Helios 机架中上市。这是新一代芯片，也是一个看看是否可以重复为期三天的启动的机会。 Anthropic 的 IPO 会提前进行，之后它将作为一家上市公司进行报告。

若AI模型能自主生成跨硬件平台的底层算子，英伟达长期构建的CUDA壁垒将面临结构性瓦解，软件定义硬件（SDH）将成为缓解算力供需失衡的终极手段。此举标志着模型厂商正从被动的硬件适配者转向主动的底层架构重构者，使得高端芯片的商业竞争核心从单一的软硬捆绑转向“模型跨平台兼容性”的标准化进程。

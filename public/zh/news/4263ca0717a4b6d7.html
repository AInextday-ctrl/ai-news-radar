Neui推出基于Go语言的AI代理Web框架

✍️ 记者 / 供稿: derstruct

Neui推出一套将Go语言Web框架与AI代理整合的栈，支持在UI中直接通过标注实现自动化操作

⚡ 核心要点提炼与关键事实

  • 【核心事件】Neui开发团队在Go语言生态与Web开发工具领域：发布整合AI代理的Web框架，支持交互元素标记、工作空间隔离与自动化处理
  • 【起因与机理】旨在简化前端与AI代理间的集成，通过上下文共享与权限 scoped 设计解决copilot类工具开发冗余问题
  • 【核心事实细节】采用Doors框架，实现Go Web开发与AI代理单栈运行。
  • 【各方立场与态度】支持长对话缓存优化，降低推理与交互成本。

📰 深度报道原文实录

Hacker News 权威实录

Neui 是一种 AI 代理和作为一个堆栈构建的 Web 框架。 Doors (Apache-2.0) 框架让 Go 团队可以构建没有单独前端和 API 层的现代交互式应用程序。 Neui 添加了代理：它在用户会话内运行，查看您让它查看的页面部分，像用户一样操作 UI，并为仅聊天无法完成的工作带来自己的工作环境。

您为用户构建的每个功能都可以立即被代理使用，并且工作环境足够强大，可以自动执行用户手动完成的工作。

开发人员在现有标记中标记代理可以查看和使用页面的哪些部分。然后，代理像用户一样单击、键入和阅读，然后应用程序自己的逻辑运行。无需编写每个操作的代码，也无需镜像状态。

工具是在服务器上运行的一个 Go 函数，无需编写端点或权限代码。开发人员决定代理可以在构建 UI 的位置看到什么并执行哪些操作，因此其访问范围仅限于每个用户并随屏幕更新。

该代理拥有自己的文件工作区、一步运行批量 UI 工作的脚本、电子表格、Web 搜索、MCP 连接器、后台任务以及长对话的自动处理。一个脚本可以调用每个工具，并且只需一步即可在整个 UI 上工作。

当用户需要您的 UI 没有的功能时，代理会当场构建它，从单个屏幕到专门的应用程序。它在具有用户权限的页面中运行，代理留在循环中做出决策。

您的用户可以获得他们已经从聊天应用程序中获得的聊天体验，无需构建或购买任何内容。

对话是提示缓存友好的，因此输入成本估计比为每个屏幕重建提示的副驾驶低 6 到 14 倍，具体取决于提供商的缓存定价。内置脚本可以完成批量工作，无需额外的模型轮转或上下文膨胀。

对话、指令和工具位于服务器上，浏览器仅发送用户的新消息。被篡改的浏览器无法添加工具、重写历史记录或更改代理被告知的内容。

每个打开的页面都在服务器上运行，并与代理工具集成。您在页面模板中标记代理可以看到和使用的内容。

运行真实的 UI。代理会像用户一样读取、填充和单击您标记的元素，并且您的处理程序将照常运行。没有要镜像的状态，也没有要重新实施的操作。

~>neui.Use{ Desc: "Customer's email", // RW: 代理读取用户浏览器中的值或写入自己的值。权限：neui.RW, } <input type="email" name="email"> 模板中的工具。根据 UI 上下文和用户权限，直接在页面模板中注册代理工具。

~(如果user.IsAdmin() {~neui。工具[退款，收据]{名称：“退款”，说明：“订单退款”，处理：订单。退款，}})持久化工具。为整个应用程序或一个会话注册的Go函数在每次聊天中都可用。内置的工作环境也是如此。

crm := neui.NewModule("crm", "登录用户的客户记录") crm.Tool("find", "通过姓名或电子邮件查找客户",customers.Find) 页面上下文。将数据附加到页面的一部分，以告诉代理它显示的内容，例如视图中的记录或如何使用它的提示。

🤖 雷达专属 AI 研判与技术透视

此技术方案标志着AI集成从“插件化”转向“原生化”，通过将UI定义与代理逻辑绑定，降低了上下文冗余与缓存开销。在自动化交互领域，这种直通式调用逻辑有望成为Go语言开发复杂企业级交互应用的新范式，直接对现有的RESTful API构建逻辑构成替代压力。

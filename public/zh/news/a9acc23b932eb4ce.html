📰 深度报道原文实录

ZDNET 权威实录

Windows 11 的最新更新在速度、性能和内存管理方面进行了改进。

Windows PC 的内存越多，执行速度就越快，尤其是在处理多个应用程序、文件和其他数据时。我的笔记本电脑有 32GB 内存，而我的台式机有 64GB 内存，两者都非常快。这是否意味着内存只有 8GB 甚至更少的计算机都是失败者？不，根据微软的说法，不是。

在周二发布的一篇新博客文章中，微软宣传了最新更新在 Windows 11 中实现的速度、性能和内存管理方面的进步。这些对 RAM 仅有 8GB 的​​ PC 的影响尤为明显，这些 PC 现在可以比以前更快、更高效地运行多个应用程序和文件。

首先是更好地利用每台 Windows 11 PC 上的现有内存。第二个是保护需要感觉即时的任务，即使使用更多内存也是如此。第三是确保关键应用程序和 Windows 需要更少的内存。是的，具有 16GB、32GB 或 64GB RAM 的计算机可以更好地处理更密集的活动。但微软希望确保 8GB 系统也能跟上步伐。

根据其自己对 8GB RAM 电脑的实验室测试，该公司声称 Windows 现在比最新更新之前的响应速度提高了 20%，多任务处理速度提高了 40%。方法如下。

随着分配更多内存，Windows 必须将不活动的应用程序和文件从 RAM 移动到硬盘驱动器。当您需要再次访问这些应用程序和文件时，您必须等待 Windows 将它们从磁盘存储移回 RAM。通常，内存较少的电脑必须进行大量的磁盘交换。

Windows 减轻此过程痛苦的一种方法是通过压缩。在这里，操作系统将不太活跃的数据缩小为较小的格式，以便它可以保留在内存中。尽管 Windows 已使用压缩多年，但 Microsoft 已对该技术进行了微调，以确定压缩程度、何时将数据从 RAM 移动到驱动器以及何时取回数据，尤其是在具有 8GB 内存的 PC 上。

微软表示，因此，Windows 现在可以在内存中保留最多 2GB 的活动数据，而不是将其移动到存储中。当您返回打开的非活动应用程序、文件或浏览器时，不太可能需要从硬盘驱动器重新加载。

打开“开始”菜单、启动文件资源管理器、右键单击文件夹或文件以及搜索项目都是需要即时完成的任务；否则，Windows 本身就会感觉迟缓。微软表示，为了在 RAM 较少的 PC 上实现这一目标，Windows 会尝试优先考虑需要完成的某些操作，同时放弃搜索索引等后台任务。

这是一个例子。更新计算机并重新启动后，Windows 需要执行一些内务处理工作。但发生的任何设置工作都不应影响打开应用程序或文件所需的时间。

据微软称，与 2026 年 1 月的版本相比，最新版本的 Windows 11 将此类任务和交互的速度提高了 20%。

然而，多任务处理对只有 8GB RAM 的 PC 造成的压力最大。为了分析这一点，微软表示，它在同一台 8GB 内存的 PC 上进行了两次测试。一项测试测量了 Windows 11 的当前版本，而另一项测试则测量了 2026 年 1 月的版本。测试人员在 Microsoft Edge 中打开了 20 个选项卡，开始播放 4K 视频，并在 Word、PowerPoint 和 Excel 中依次启动大文件。该公司表示，当前版本的 Windows 比其前身快 40%。

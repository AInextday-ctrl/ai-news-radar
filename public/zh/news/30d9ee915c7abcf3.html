Anthropic对Claude Code增设规则防侵权

📖 阅读原资讯官网报道 ↗
Anthropic确认对Claude Code实施新限制以防范复刻特定第三方游戏，强调使用AI侵犯知识产权违反其使用政策

⚡ 核心要点提炼与关键事实

  • 【核心事件】Anthropic公司在Claude Code开发辅助工具场景：增设提示词规则，防止模型复刻特定第三方游戏并遏制侵权
  • 【起因与机理】规避日益严峻的AI版权纠纷与法律风险，严格执行反侵权使用政策
  • 【关键技术规格】Anthropic对Claude Code增设防复刻提示规则。
  • 【观点态度】旨在规避知识产权侵权风险并严守合规底线。

AI写代码正爽呢，法务部突然跳出来拔了网线。版权大棒一挥，大模型连高仿个贪吃蛇都成了赛博违禁品，看来离代码界的“防盗版验证”被AI全面内化不远了。

Tom's Hardware 权威实录

与此同时，我们现在收到了有关逆向工程工作被阻止的直接报告，而网上投诉也在增加。

在完整的推文中（您可以在下面阅读），Addy Osmani 表示“[Anthropic] 在 Opus 5.5 上的 Claude Code 提示中添加了两句话，以引导其远离重新创建其他人的特定游戏，因为使用 Claude 侵犯知识产权违反了[其]使用政策。”他接着表示，原创游戏的工作应该继续进行，Anthropic 正在迭代规则，试图“达到适当的平衡”。

我们在 Opus 5.5 上的 Claude Code 提示中添加了两句话，以阻止其重新创建其他人的特定游戏，因为使用 Claude 侵犯知识产权违反了我们的使用政策。原创游戏、类型游戏以及根据您自己的设计和资产构建的游戏旨在继续发挥作用。我们将继续迭代以确保我们取得正确的平衡。与此同时，如果克劳德拒绝了属于你的东西，请将其发送给我。2026 年 10 月 30 日

目前还不清楚这些句子可能是什么，但考虑到 Osmani 的用词选择，这些句子可能确实是 X 用户 Chasm 发布的屏幕截图：“要构建原创游戏、某种类型的游戏以及根据用户自己的设计和资产构建的游戏。不要构建特定现有游戏的娱乐版，即使它被重命名或称为原创。”

在我们之前的报告中，我们已经链接到了 Claude Code 自己的 GitHub 存储库中最近提出的问题，其中包括用户抱怨人工智能助手拒绝处理他们的游戏或逆向工程任务。据我们所知，与游戏相关的阻塞似乎仅限于使用 Claude Code 和 Opus 5.5 模型的组合。如果这一点被证明是正确的，那么用户应该能够通过使用 Ollama 等其他工具调用 Opus 或通过某种包装器转发特定请求来避开限制。

关于逆向工程的封锁，我们已经收到了直接确认。第一个来自我们的校友贾里德·沃尔顿（Jarred Walton），他试图对他正在开发的软件进行检查。他指出，直到昨天 10 月 31 日，此类工作都没有出现任何问题，而切换到 Opus 4.8 让他可以继续工作。

沃尔顿推测，人类可能在代码中添加了一条专门用于逆向工程的新规则。考虑到这个时间点，再加上上周出现的其他拒绝报告的事实，可能表明该公司可能会以与视频游戏相关内容相同的方式摆弄网络安全相关规则。

我们还收到了一名员工的熟人发来的屏幕截图，他要求 Opus 5.5（通过代码）尝试对产品激活进行逆向工程，这一请求同样触发了安全措施。与此同时，注意到 Claude Code 似乎阻止逆向工程继续增加，据称现在有一名 Redditor 的帐户因使用 Opus 5.5 和逆向工程 Anything 而被暂停，然后又恢复。该公司有一个持续的网络验证计划，只有获得批准的实体才能访问全套前沿模型的网络安全功能。

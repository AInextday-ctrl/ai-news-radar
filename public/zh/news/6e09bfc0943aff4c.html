思科与OpenAI启动开源基础设施防护计划

✍️ 记者 / 供稿: Mike Wheatley

思科与OpenAI联手发布安全基础设施项目及Shirudo工具，旨在应对AI加速带来的“零日”自动化网络攻击

⚡ 核心要点提炼与关键事实

  • 【核心事件】思科系统工程副总裁兼安全CTO Thomas Graf、OpenAI集团在企业级安全基础设施构建领域：发布安全基础设施项目，并推出Shirudo开源防御工具
  • 【起因与机理】应对AI驱动的网络攻击导致漏洞修复周期失效的现实风险
  • 【关键技术规格】核心动因：应对AI驱动的自动化漏洞挖掘与负向防御时间窗口。
  • 【行业影响与走向】后续影响：推动行业从补丁式安全向设计即安全（Secure-by-Design）转型。

📰 深度报道原文实录

SiliconANGLE 权威实录

网络犯罪分子已经能够在几秒钟内发现软件中的漏洞并利用它们，而这一切都归功于人工智能。企业需要更好的方式来保护自己，因此世界顶级人工智能公司之一 OpenAI Group PBC 与思科系统公司合作，正在加紧推出解决方案，这是理所应当的。

他们刚刚宣布了一项新的开源且雄心勃勃的计划，称为“安全基础设施项目”，该计划旨在确保所有人工智能计算基础设施的设计都是安全的，并且能够防御闪电般快速的人工智能驱动的攻击。该计划中的第一个项目是 Shirudo，旨在在修补基础设施系统之前自动保护其免受关键漏洞的攻击。

思科安全首席技术官兼工程副总裁 Thomas Graf 在一篇博文中解释说，业界一直将安全视为事后的想法，本质上是事后才将安全性附加到系统上的东西。它已经摆脱了这一点，因为世界上大部分计算基础设施都是为以人类速度进行的工作流程而构建的。但随着人工智能模型的出现，可以在几秒钟内发现并找出如何利用漏洞，这种反应式安全已经不够了。

Graf 表示，即使是现在，当在广泛使用的软件中发现重大漏洞时，也可能需要数周甚至数月的时间才能找到修复方案并确保每个主要系统都针对该漏洞进行修补。他说：“鉴于平均利用时间已变为负数，这个时间范围已不再可接受，这意味着越来越多的漏洞在公开披露之前就已被利用。” “随着人工智能模型和网络安全能力的进一步发展，这只会加速，成为开放权重模型的规范。”

为了应对此类自动攻击，思科和 OpenAI 认为必须从头开始重建基础设施，并牢记安全性。他们认为，是时候放弃静态防御并采用默认强化的、不可变的、可从之前的“良好”状态重建的系统，这样用户就可以在受到攻击时快速恢复。为此，基础设施系统必须基于可信平台模块，并利用强化学习技术来安全地测试自身的防御能力，以便在面临来自先前未知向量的新型网络攻击时能够适应。

Graf 表示，做到这一点的关键是确保运行时工作负载的安全，这就是为什么思科和 OpenAI 计划的最初重点是 Shirudo，这是开源 Tetragon 运行时安全项目的演变，旨在为 AI 代理提供自主防御。

Shirudo 得名于日语中的“盾牌”一词，它基于扩展的伯克利数据包过滤器或 eBPF，这是一种 Linux 内核技术，其作用类似于操作系统中的一种沙箱。与 JavaScript 如何使 Web 浏览器无需重新启动即可进行编程类似，eBPF 允许小型、经过验证的程序在 Linux 内核内运行，以观察应用程序的活动并修改其行为，而无需更改其源代码或重新启动它。

Graf 解释说，Cisco 和 OpenAI 选择使用 eBPF 是因为没有其他真正的替代方案。以人为本的安全控制台和策略语言对于人工智能代理来说太慢了，并且会限制他们的生产力。

通过公开可编程内核接口，eBPF 使 AI 代理能够捕获粒度遥测、评估监控模式下的缓解措施并在几毫秒内部署加密签名的防护罩。因此，可以实时阻止利用未知漏洞的网络攻击，而不会对其实时工作负载造成干扰。

思科总裁兼首席产品官 Jeetu Patel 表示：“没有什么比为安​​全团队提供所需的工具来应对他们面临的人工智能威胁的速度更重要的了。” “我们需要自卫基础设施，以代码的速度运行，实时学习并自我保护，直到补丁安全推出。”

OpenAI 在这方面的作用是证明 eBPF 能够胜任这项工作，并且它已经将 Shirudo 部署为由 Codex 编码代理提供支持的代理控制平面的一部分。当给出新漏洞的详细信息时，Codex 可以使用 Shirudo 自主构建漏洞重现器，然后设计缓解策略。然后，它会验证缓解代码并在所有受影响的节点上部署加密签名的防护罩。

这两个合作伙伴最近针对 OpenJDK 中名为 Java4Shell 的严重新漏洞测试了 Shirudo，它能够快速生成 Java 字节码，并将其直接注入正在运行的 Elasticsearch 代理中，以阻止可能危害系统的恶意 Base64 覆盖。

OpenAI 联合创始人兼总裁 Greg Brockman 表示，Shirudo 的目标是帮助公司保护其系统免受新威胁，直到他们能够构建和部署更持久的补丁。 “当一个团队找到更好的方法来保护系统时，其他团队就不必从头开始，”他解释道。

为此，思科和 OpenAI 表示，他们欢迎开发人员、内核工程师、平台构建者和安全专家在其更广泛的安全基础设施项目中就 Shirudo 和其他计划进行合作。

🤖 雷达专属 AI 研判与技术透视

安全防御逻辑正从“漏洞修补”向“架构免疫”范式转移，此合作标志着传统网络巨头开始通过集成AI原生的防御模型来重塑云原生算力边界。Shirudo通过强化学习实现的自我防御机制，将显著提高算力平台的防御韧性，这可能迫使云服务提供商重构其底层TPM（可信平台模块）信任链以满足合规审计要求。

美团发布LongCat-2.5：全国产算力底座下的万亿参数模型

📖 阅读原资讯官网报道 ↗
美团发布1.6万亿参数多模态Agent模型LongCat-2.5，完全基于国产硬件训练，性能对标Claude Opus 5

⚡ 核心要点提炼与关键事实

  • 【核心事件】美团（Meituan）LongCat研发团队在AI模型开源与技术发布平台：发布1.6万亿参数MoE模型LongCat-2.5，支持多模态输入，采用4-bit量化技术适配国产芯片
  • 【起因与机理】构建自主可控的AI Agent算力底座，解决复杂多步任务执行与长序列推理需求
  • 【关键数据与实测】采用MoE混合专家架构，总参数量1.6万亿，激活参数480亿。
  • 【各方立场与态度】具备百万Token长窗口能力，通过沙箱任务集训练强化代码与Agent推理性能。

🤖 雷达专属 AI 研判与技术透视

该模型的核心意义在于验证了在完全去Nvidia环境下，通过MoE架构优化与软硬件协同调优，可以实现对国际第一梯队模型的基准追赶。这一实践证明了国产AI集群在处理大规模Agent任务时，通过量化策略与任务沙箱模拟训练，已跨越了从可用到可商用的关键技术门槛，这将对国内云厂商及AI基础设施的供应链独立性产生显著示范效应。

THE DECODER 权威实录

美团发布LongCat-2.5权重，这是一个为AI智能体构建的1.6万亿参数模型。它完全在中国硬件上进行训练，其性能达到了 Claude Opus 5 等美国模型几个月前在编码基准上达到的水平。

在该模型正式发布一周后，中国食品配送公司美团的 LongCat 团队发布了 LongCat-2.5 的权重。 LongCat-2.5 是为能够自主完成长期、多步骤任务（尤其是编码）的代理而构建的。据美团称，它在多项基准测试中接近西方顶级机型。

LongCat-2.5 是一个专家混合模型，它只为其处理的每个令牌激活其专用子网络的子集。在 1.6 万亿个参数中，每个代币大约有 480 亿个参数处于活跃状态。通过 API，该模型可以一次处理多达 100 万个令牌，并生成长达 128,000 个令牌的响应。它可以理解文本、图像和视频，以文本形式做出响应，并允许用户打开和关闭推理。

LongCat-2.5 将图像转换为token

LongCat-2.5 建立在其前身 LongCat-2.0 的基础上，并增加了图像理解功能。许多多模态模型事后都安装了单独的图像编码器。 LongCat-2.5 相反，将图像转换为模型与文本一起处理的标记，这是当今法学硕士的标准做法。该方法借鉴了 LongCat-Next 研究模型，旨在改进视觉编码、设计和 3D 任务。

LongCat-2.5 以原始分辨率将图像分解为模型与文本一起处理的离散标记。 |图片：美团[/标题]

对于强化学习，该团队使用了来自 GitHub 拉取请求的真实软件任务以及重新创建的代理故障。为了确保模型在训练期间确实解决了任务，开发人员在训练环境中阻止了互联网访问，删除了 Git 历史记录和缓存文件，并让语言模型检查其解决方案是否存在技巧。该团队还将几个专门的教师模型用于代理工作、推理和对话的功能提炼到 LongCat-2.5 中。

美团从真实的 GitHub 存储库生成训练任务，并在沙箱中阻止 Web 搜索和 Git 历史记录等快捷方式。 |图片：美团[/标题]

美团将专家的权重和激活量化到 4 位精度，中国芯片可以本地处理。在美团的负载测试中，与 8 位版本相比，即时处理吞吐量提高了 43.3%，响应生成吞吐量提高了 42.77%。美团表示，准确性与未压缩模型保持一致。

该版本可在单独的存储库中找到。自托管指南描述了由 Atlas A2 系列的 194 个华为 Ascend 加速器组成的集群。两个处理图像处理，64 个处理提示摄取，以及 128 个处理响应生成。没有针对 Nvidia GPU 的指南。

LongCat-2.5 在终端任务上稍微落后于 Opus 5

LongCat 团队在 Terminal Bench v2.1 上获得了 88.4 分，这是衡量代理解决命令行任务效果的基准。美团将 Claude Opus 5 列为 89.1，GPT-5.6 Sol 为 88.8，Deepseek-V4.1-Flash 以 90.6 名列榜首。

DeepSWE 测试模型在真实代码存储库中修复错误的效果。这里，LongCat-2.5 从 9.7 分跃升至 64.6 分，落后于表中除 Claude Opus 4.8 之外的所有其他模型，其中 Deepseek-V4.1-Flash 领先，得分为 74.2，GPT-5.6 Sol 得分为 72.7。较新的 Claude Opus 5.5 和 GPT-6.1 Sol 未包含在表中。

在美团自己的评估中，LongCat-2.5比其前身有了很大的改进，并且在多个代理基准上接近Claude Opus 5和GPT-5.6 Sol。 |图片：美团[/标题]

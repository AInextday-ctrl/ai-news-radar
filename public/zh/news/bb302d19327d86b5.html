OpenAI发布GPT-6.2系列模型，主打高性价比与科学推理能力

✍️ 记者 / 供稿: OpenAI

OpenAI推出GPT-6.2 Astra与Sol模型，前者侧重复杂专业工作与科学推理，后者专注日常任务，通过大幅降低API成本实现高性能部署

⚡ 核心要点提炼与关键事实

  • 【核心事件】OpenAI在企业产品发布：发布GPT-6.2 Astra/Sol模型及API降价策略
  • 【起因与机理】通过提升推理效率与降低使用门槛，争夺生产力工具与科研AI市场份额
  • 【关键数据与实测】API价格整体下调20%并大幅增加缓存折扣以优化成本架构。
  • 【各方立场与态度】GPT-6.2 Astra在多步骤推理与科学基准测试中创下新高。

专业工作的新标准

我们推出了 GPT-6.2 Astra，这是我们为您最困难的项目设计的新前沿模型，以及 GPT-6.2 Sol，我们为日常工作设计的高效、多功能模型。两种模型都能以更少的输出令牌在要求较高的任务上提供更好的结果，因此您可以在使用限制内完成更多工作。对于企业和开发人员来说，这意味着以规模化的成本实现前沿性能。

GPT-6.2 Astra 为复杂专业工作中的人工智能设定了新的质量标准。它的幻灯片、电子表格和文档读起来不太像人工智能，而是更严格地遵循您提供的模板和您所在领域的惯例。它编写更清晰的代码并构建外观和工作效果更好的前端，特别是对于网站、游戏和 3D 设计。

在测试多步骤专业工作的 Agents’ Last Exam 中，GPT-6.2 Astra 创下了新高，比 GPT-6 Astra 高出 5.2 分，而成本却不到 GPT-6 Astra 的三分之一，比 Claude Fable 5.2 领先 5.5 分，而成本仅为 GPT-6 Astra 的 5%。

我们相信 GPT-6.2 Astra 对于科学家来说是世界上最好的模型。它为 Terminal-Bench-Science 0.1 设定了新的高度，该版本测试模型在终端中执行科学工作的能力。 GPT-6.2 Astra 的得分比 GPT-6 Astra 高 9 个百分点，而成本却不到 GPT-6 Astra 的三分之一。它还创下了 Vals 科学指数的新高，该指数要求模型解释真实的生物数据并进行实验以推断模拟系统的工作原理。

在 API 中，GPT-6.2 Astra 的输入和输出代币价格比 GPT-6 Astra 低 20%，缓存输入有 60% 的折扣（输入 8 美元，缓存输入 0.40 美元，输出 40 美元，均为每百万代币）。 GPT-6.2 Sol 保留 GPT-6.1 Sol 的 API 代币价格。在多个基准测试中，这两种模型都接近或优于其他领先模型，而每项任务的成本仅为其一小部分。

GPT-6.2 Sol：我们日常工作的首选模型

与 GPT-6.1 Sol 相比，GPT-6.2 Sol 更智能、更高效，让您在相同的付费套餐中完成更多任务。它通过多步骤代理工作流程提供支持，书写清晰自然，并且协作直观。 OpenAI 的许多员工都将其用作技术和非技术任务的默认模型。

在 Cognition 的 FrontierCode 2.0 中，GPT-6.2 Sol 与 GPT-6.2 Astra 相差不到 0.5 个点，成本约为 GPT-6.2 Astra 的五分之一（均为最大值）。

它的速度和智能也使其成为人们在工作之外求助于人工智能的重要任务的理想选择。在我们最近发布的 LifeVal 评估（衡量具有挑战性的日常任务的性能）中，GPT-6.2 Sol 的得分超过了 GPT-6 Astra，成本约为 GPT-6 Astra 的七分之一。

符合行业标准的专业输出

我们训练 GPT-6.2 Astra 创建更清晰、设计更好的幻灯片、电子表格和文档，更严格地遵循专业人士在法律、销售、财务和会计等领域使用的惯例。写作更加直接和具体，一般性要点和填充物更少。

Harvey LAB-AA v1.1 使用法律作业来测试模型是否可以在源文档中找到相关事实，将其应用到详细的摘要中，并生成满足每项要求的准确交付成果。 GPT-6.2 Astra 树立了新的技术水平，以大约六分之一的成本将 Claude Fable 5.2 的通过率提高了一倍以上。 Astra for Law（我们为律师配置的 GPT-6.2 Astra）在此基准测试中得分甚至更高。

我们的内部 GDPval v2 基准是 GDPval 的下一代迭代，用于衡量咨询、金融和设计等领域实际项目的复杂、长期工作流程。 GPT-6.2 Astra 在我们测试的模型中领先，比 GPT-6 Astra 提高了 6.2 个百分点，同时使用的输出代币减少了 22%。 GPT-6.2 Sol 比 GPT-6.1 Sol 提高了 5.3 点。

作业簿和备忘录

构建估值工作簿或撰写投资备忘录首先要在源文件中查找相关数据，并弄清楚它们如何组合在一起。 Artificial Analysis 的 AA-AnalystAgent 测试适用于真实的电子表格和报告。在一项任务中，模型使用加州医疗补助的支出报告来计算该计划在医疗运输上的支出。 GPT-6.2 Astra 创下新高，在所有五次独立尝试中正确回答了 62.5% 的问题。

GPT-6.2 Astra 是我们迄今为止设计幻灯片和遵循幻灯片模板的最佳模型，无论是给定原始文件还是屏幕截图。它可以将布局、颜色和版式匹配到精确的字体大小，并将模板的书写风格带入新幻灯片中。早期测试人员发现这些套牌更容易直接使用，编辑次数也更少，这要归功于陈述主要内容的标题和专注于读者需要的细节的简洁正文。

计算机使用和交互式网页设计

GPT-6.2 Astra 更精确的计算机使用使其能够在 CAD 和模拟工具中细化到各个零件和连接。工程师可以使用这些额外的细节来检查组件的配合情况，查看负载随着设计的变化而变化的位置，并在构建原型之前测试修订。

我们要求 GPT‑6.2 Astra 可视化山路上汽车的底盘动态。 Astra 创建了 3D 模型并编写了一个 Python 解算器来模拟轮胎和悬架之间的复杂动力学，然后在 Blender 中对结果进行动画处理。这使得工程师能够快速测试新设计并随着时间的推移提高仿真精度。

机械设计与装配

GPT-6.2 Astra 可以对机械系统的各个部分进行建模，为工程师提供了一种展示其如何组合并测试设计变更如何影响其行为的方法。

我们的团队使用 GPT-6.2 Astra 将芝加哥滨海城塔楼的扇形阳台变成了一盏灯。该视频讲述了从参考照片到 CAD 修订再到手工组装的实体灯的设计过程。该网站由 GPT-6.2 Astra 生成，可用于创建您自己的纸灯。

GPT-6.2 Astra 为网页设计带来了更强大的视觉推理，选择为每个网站提供独特外观的布局和图像，并围绕网站的实际目标构建元素。

这些视觉推理和计算机使用方面的进步也延续到了 3D 设计中。 GPT-6.2 Astra 和 Sol 可以将书面简报转变为交互式浏览器体验，从可以玩的弹球桌到可以从不同角度探索的罗马斗兽场的娱乐。在 Artificial Analysis 的 AA-3D 中，人类评委尝试根据同一提示构建的两种盲体验，并投票选出他们喜欢的一种。 GPT-6.2 Astra 以 1,318 Elo 排名第一，其次是 Claude Fable 5.2（1,271）和 GPT-6.2 Sol（1,259）。

高效的工作流程和简洁的代码风格

GPT-6.2 Astra 对如何执行任务有更好的判断，包括将其工具和工作与工作流程相匹配，以及知道何时使用插件而不是计算机。

在编码方面，GPT-6.2 Astra 更擅长在现有代码库中实现和测试复杂的更改。早期的测试人员报告了更清晰的代码风格和更集中的测试，并且修改次数更少。

网络安全能力

GPT-6.2 Astra 和 GPT-6.2 Sol 标志着网络能力的又一次重大飞跃。他们更有效地发现和利用漏洞，编写更安全的代码，并生成更好的补丁，并在多项评估中获得了显着的令牌效率提升。与 GPT-6 Astra 一样，6.2 Astra 和 Sol 也满足我们的准备框架下的网络安全关键阈值。

由于功能增强，我们推出了 GPT-6.2 Astra 和 Sol，为高风险网络安全援助提供更严格的保障措施。这些保护措施降低了误用风险，但也限制了一些合法的漏洞研究和安全测试工作流程。通过 OpenAI Daybreak，防御者目前可以在 Daybreak Blue 上访问 GPT-6 Sol，减少网络拒绝，此外还可以在 Daybreak Red 上访问 GPT-6 Astra 的 alpha 版，以及在 Daybreak Red 上进行高级授权安全测试的 GPT-6 Cyber​​。我们将努力将 GPT-6.2 模型引入 Daybreak。

我们在下面重点介绍关键基准测试结果，使用内部测试配置并禁用网络安全保障措施和分类器。有关完整结果和方法，请参阅随附的系统卡。

为网络防御者提供优势

开发人员越来越依赖编码代理来编写生产软件，尽管功能更强大的代理降低了发现和利用漏洞的障碍。 PHP2Shell 展示了人工智能如何帮助研究人员发现关键缺陷。借助 GPT-6.2 Astra 和 Sol，我们将防御能力作为核心焦点，引入新的训练信号来帮助开发人员预防和修复这些缺陷 - 从一开始就编写安全代码并生成保留预期行为的补丁。

我们正在部署 GPT-6.2 Astra 和 Sol，并提供迄今为止最强大的保障措施。我们加强了限制并加强了用于监控模型并在需要时进行干预的系统。

与 GPT-6 Astra 一样，除了满足网络安全的关键阈值之外，GPT-6.2 Astra 和 Sol 还满足我们的准备框架下的生物和化学能力的高阈值。我们已经实施了保护措施来减轻相关风险，同时增加了对一系列潜在的双重用途生物和网络安全请求的限制。

有关我们的防护措施和测试的更多详细信息，请参阅 GPT-6.2 系统卡。

人工智能研究能力及保障

GPT-6.2 Astra是我们第一个对外发布的满足AI自我提升高门槛的模型，衡量模型加速AI研究的能力。 “高”称号反映了我们的评估，即相对于 2024 年的基准，该模型的影响相当于为每位 OpenAI 研究人员提供了一名额外的、能力很强的研究工程师作为助理。我们跟踪这种能力是因为有助于开发未来人工智能系统的模型也可能会给安全带来新的风险，比如加速进步的速度快于保障措施或人类监督所能适应的速度。

为了解决这些风险，我们对训练和部署模型的方式进行了更多的监督和控制。在扩大对 GPT-6.2 Astra 的内部访问之前，我们评估了其一致性并验证了每个阶段所需的保护措施是否到位。我们加强了研究环境的遏制，并用我们最有能力的模型测试了这些保护措施。我们还构建了控制室，这是一个跟踪研究工作量的系统，可以在需要干预时停止进一步的模型输出。我们的扩展监控检查模型在内部工作负载和支持的外部部署中的推理和操作。它可以自动标记未经授权的行为，并在支持的情况下暂停工作负载或对话。

在大多数对齐评估中，这两种模型的表现与GPT-6 Astra相似，并且在模拟工作场所任务中采取的不当行为较少。然而，在两个测试中，他们更有可能忽略那些阻碍他们工作的障碍，比如丢失的文件或不可用的搜索工具。我们在食品法典中增加了大量减少这些遗漏的说明，我们正在继续调查这种行为。

定价和供货情况

从今天开始，GPT-6.2 Astra 和 Sol 可供 ChatGPT Work 和 Codex 中的所有 Plus、Pro、Enterprise 和 Edu 用户使用。 Pro 500 订阅者可以使用任一型号的 Ultrafast。从 GPT-6.2 Sol 开始，我们还首次为 Pro 200 订阅者带来 Ultrafast。一旦工作区管理员启用，符合条件的企业和教育用户将获得相同的访问权限。开发人员还可以通过 OpenAI API 访问 gpt-6.2-astra 和 gpt-6.2-sol，这两种模型在发布时都可以使用 Ultrafast。

GPT-6.2 Astra 每项任务的成本明显低于 GPT-6 Astra，这得益于更好的令牌效率、输入和输出令牌 20% 的折扣以及缓存输入令牌 60% 的更深折扣。每百万代币的标准 API 费率为输入 8 美元、缓存输入 0.40 美元、输出 40 美元。 GPT-6.2 Sol 继承了 GPT-6.1 Sol 的每百万代币 2 美元的输入费率、0.10 美元的缓存输入费率以及 10 美元的输出费率。

对于 GPT-6.2 Astra 和 Sol，为了提高缓存重用、帮助降低成本和延迟并保留轮流推理，我们建议保持提示前缀不变并向对话附加新指令。

OpenAI此举标志着模型竞争逻辑从单一的参数规模竞赛转向“单位推理成本下的任务完成度”优化，意在通过极具侵略性的定价挤压竞争对手的生存空间。通过针对科学计算（Terminal-Bench-Science）的专项优化，其目标已明确指向高价值科研数据资产的处理权，这将迫使云服务厂商进一步压缩大模型托管的利润率。

Revolut利用OpenAI模型升级反洗钱风控

✍️ 记者 / 供稿: OpenAI

金融科技公司Revolut接入OpenAI模型，通过部署智能反洗钱（FinCrime）代理实现交易监测与风险调查自动化

⚡ 核心要点提炼与关键事实

  • 【核心事件】Revolut (金融科技公司)；OpenAI (技术服务方)在金融合规与反欺诈业务部门：部署基于GPT-5.5的FinCrime智能代理，实现交易风险自动甄别与调查
  • 【起因与机理】全球交易量爆发导致合规人力缺口，需通过AI提升风险监测效率与缩放能力
  • 【关键数据与实测】30–60% reduction in coding time from task start to feature merge。
  • 【涉及范围与推进】合规逻辑：将复杂合规规则注入模型，确保自动调查流程符合金融监管要求。

OpenAI 官方动态 权威实录

借助 OpenAI 模型和 Codex，Revolut 为其团队提供了更多空间来解决从软件工程到金融犯罪等复杂问题。

减少从任务开始到功能合并的编码时间

将七年的设计文档转化为人工智能可读的背景

通过 Codex 进行安全代码审查，节省成本

每天走得更快

Revolut 的诞生是为了挑战人们与金钱互动的方式。这一雄心现已覆盖 40 多个市场、80 万家企业以及过去 12 个月增长了 23% 的消费者群。

再加上公司文化要求小型、精干的团队能够快速行动，因此事实证明 ChatGPT 和 Codex 是天生的搭档也就不足为奇了。

Revolut 全球业务营销主管 Kim Maniovich 表示：“对高素质 Revolut 人员的完美描述是能够快速识别问题、推断解决方案、设计四种方案、确定这四种方案中最好的一种，然后将其推向市场。”

“与 OpenAI 合作使我们能够以极其精简、经济高效且真正适合我们独特工作方式的方式构建许多此类解决方案。”

但更快的行动只是机遇的一部分。对于 Revolut 来说，更大的问题是，当有才华的人花更少的时间在完成工作的机制上，而花更多的时间来解决可能从根本上改变金融服务的问题时，会发生什么。

从规模与影响力相结合的地方开始

随着Revolut的发展，保护客户的工作也变得越来越复杂。根据一份报告，全球超过一半的成年人报告在2025年遭遇过骗局。

对于Revolut来说，每笔交易都为其提供了另一个机会，可以识别可疑活动，调查潜在风险，并为其客户实施强有力的量身定制保护。但这些交易的庞大数量远远超过了任何一家银行可用的人力资源。

人工智能主管David Abitbol表示：“我们今天能用人工智能解决的最大问题是人类的规模与我们的需求之间的关系。”这就是为什么Revolut最大的人工智能应用之一是由OpenAI模型驱动的FinCrime代理。

该代理可以检查信息，应用Revolut的规则并自动完成定义的流程，而不是要求调查人员手动处理每个符合条件的案例。

GPT-5.5 的发布是一个转折点。 Abitbol 表示，就在那时，这些模型已经变得足够强大且具有成本效益，Revolut 可以将筛选和调查工作流程完全委托给代理。其结果是，在不按需求增加调查员人数的情况下，监控交易的能力得到提高。

信息安全工程师 Mo Amiri 补充道，“这直接转化为我们的客户可以信赖的更强大的保护和更具弹性的系统。”

“快速行动，但建立信任”很容易成为 Revolut 的内部工程口号。虽然 Abitbol 指出 Codex 已将编码时间缩短了 30-60%，但他也明确指出某些护栏是不容协商的。

“我们有一个系统框架，公司中使用人工智能构建任何东西的任何人在开发、A/B 测试和业务指标预测方面都拥有相同的一套标准，”他说。 “因此，整个公司的每位工程师都必须遵守相同的质量标准。我们开始以合理的成本获得足够的情报，从而可以将初步调查和筛查越来越多地委托给代理。”

授权实施，而不是问责

对于高级平台工程师 Dmitry Pitik 来说，在构建内部代码审查服务时，编码时间明显减少了 30-60%。他设计了该系统，将其分解为功能，并最初认为他需要一个开发团队来实现它。

“我意识到我不需要整个开发团队来实现这个，”他回忆道。 “我可以启动不同的代理并为每个代理分配特定的任务。” Codex 成为了他的实施团队，而 Dmitry 则花了更多时间设计系统、规划工作并审查返回的结果。

这是 Abitbol 在 Revolut 中看到的一种模式。当 Codex 将容量返还给工程师时，他们正在利用回收的时间“花更多时间讨论设计和最佳解决方案。因此，我们花更多时间设计而不是实施。”

这并没有消除对工程专业知识的需求，它只是改变了专业知识的应用领域。 “每个开发人员都对他们生成的代码负责，我们不会盲目信任人工智能，”皮蒂克说。结果是不同的工作分工：人工智能可以帮助实施，而工程师则将更多注意力放在决定软件是否有用、可靠和值得构建的决策上。

这笔开销是值得的。当 Codex 处理一项任务时，Pitik 可以并行处理另一项任务。正如金·马尼奥维奇（Kim Maniovich）解释的那样，这种多任务处理对于公司来说至关重要，因为公司里的普通员工都从事“三份不同的工作”。使用 Codex 创建了一个良性的（如果具有挑战性的）飞轮，“我们设定的目标逐月变得更加激进，但也更容易实现。所以标准不断提高。人工智能使这成为可能。”

Revolut 利用这种新发现的能力所做的事情包括开发一种工具来为内部应用程序和面向外部的产品构建 Web UI。

或者在一天之内将七年的设计文档转化为人工智能可读的上下文，为旨在帮助设计师更有效地工作的工具奠定基础。该练习说明了人工智能如何使积累的组织知识更容易获取，从而减少使用复杂系统所需的工作量。高级设计师德米特罗·巴甫洛夫 (Dmytro Pavlov) 表示：“我们可以将注意力从那些重要但没有人工智能就很难完成的事情转移到对客户重要的事情上。”

“我意识到我不需要整个开发团队。我只需启动不同的代理并为他们分配任务即可。”

建立对系统的信任

Mo Amiri 的工作是确保所有这些速度都与安全相匹配——不仅是为了客户，也是为了 Revolut 自己的员工。这让他同时对人工智能有了两种看法：它如何帮助 Revolut 调查问题，以及团队在安全部署它之前需要什么。

例如，在网络钓鱼调查中，分析师曾经必须收集电子邮件、检查其链接和附件、追踪发件人并手动收集证据。 “借助更强大的人工智能工具，我们可以立即发现这些联系，并深入挖掘真正重要的问题，”他说。

虽然人工智能会跑腿并向调查员提供结构化的案例，但仍由个人审查原始记录，决定解释是否合理并批准任何行动。

当团队将新的人工智能应用程序引入 Revolut 时，Amiri 也采用了同样的思维。他遵循完整的链条：系统看到什么信息，这些信息去了哪里，它可以访问哪些工具，它可以通过该访问做什么，以及当出现故障时会发生什么。他还测试了表面上令人信服的结论是否实际上得到了证据的支持。

“最关键的决定始终是关于问责制，”他说。 “如果人工智能工具建议更改代码，人类工程师需要充分理解该更改才能支持它。这直接推动了我们设计审核流程的方式，为开发人员提供他们所需的上下文，而又不会扰乱他们的日常工作流程。”

对于 Revolut 来说，保障措施与创新密不可分。它们有助于创造条件，使团队可以自信地采用更强大的技术。 “这就是你如何赢得对人工智能的真正信心，”他解释道，“通过预先做出深思熟虑的决定并进行测试。”

“通过预先做出深思熟虑的决策并随时进行测试，您可以对人工智能产生真正的信心。”

结果一目了然

从任务开始到功能合并的编码时间减少 30–60%

一名工程师通过将实施任务委托给多个 Codex 代理来构建内部代码审查服务

有一天，将大约七年开发的现有设计系统文档转换为人工智能可读的上下文

一项重要的安全代码审查任务可节省一到两天的时间

通过 FinCrime 代理筛选更多交易，无需一对一扩大调查人员规模

从一个值得解决的问题开始。 Revolut 已将人工智能应用于需求增长最快且客户利益最高的领域。

用速度来提高雄心，而不是降低标准。编码和调查节省的时间为更好的设计、更难的问题和更重要的工作创造了空间。

让人们陷入困境。人工智能可以收集证据、编写代码并建议采取行动。一个人仍然需要充分理解这项工作才能支持它。

在扩大规模之前建立信任。清楚系统可以看到什么、可以做什么以及出现故障时会发生什么，然后随时测试这些决策。

让你的知识有用。当人工智能能够达到清晰、组织良好的背景时，它的工作效果会更好。同样的练习通常会表明组织本身需要更清晰的地方。

接下来是什么

Revolut 已经展示了人工智能如何增加其团队可以尝试的工作量和复杂性。它的下一个机会是将能力、判断力和设计结合到客户与金钱的互动方式中。

Abitbol 设想了一个更具对话性的界面，客户可以在其中要求 Revolut 帮助完成日常财务任务：冻结卡、管理订阅或寻找旅行储蓄的方法。巴甫洛夫看到了这种体验背后的设计挑战——将复杂性转化为一致、熟悉且易于使用的东西。

Kim Maniovich 将未来与推动工作的文化联系起来。 “我希望我们能够秉承我们每天所奉行的价值观——这种毫无歉意的雄心、永不安定的渴望——并让人们通过我们为他们打造的产品将其应用到自己的生活中。”

随着人工智能让构建变得更加容易，差异化因素就变成了知道要构建什么，并保持判断、标准和客户理解以做好构建。对于 Revolut 来说，这是工作中智能的更大承诺：花在完成工作的机制上的时间更少，并且有更多的能力让金融服务对每个人来说更安全、更简单、更有用。由获得许可的 Revolut Group 实体提供的银行服务。访问 Revolut.com。

Revolut的实践证明了AI在金融合规领域从“辅助决策”转向“全流程托管”的技术跨越。GPT-5.5在成本控制与逻辑严密性上的提升，使得金融机构能够将高频、重复的合规审计任务剥离给智能代理，这是银行IT基础设施实现轻量化扩张的标志性应用案例。

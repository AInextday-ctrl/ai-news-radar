首个完全自主化AI漏洞挖掘框架现身

✍️ 记者 / 供稿: SiliconANGLE

谷歌威胁情报小组发现攻击者利用无需人工干预的AI框架，实现对软件补丁的自动化漏洞挖掘与利用

⚡ 核心要点提炼与关键事实

  • 【核心事件】谷歌威胁情报小组（GTIG）在暴露的暂存服务器：首次发现无人工干预的自动化AI漏洞挖掘框架，能够实现补丁分析至自动化漏洞生成的全链路攻击
  • 【起因与机理】利用大型语言模型处理已知补丁逻辑的效率远超人工寻找零日漏洞
  • 【核心事实细节】首次发现无需人类介入的完全自主攻击AI框架。
  • 【各方立场与态度】网络安全防御门槛因攻方效率暴增而被迫重构。

📰 深度报道原文实录

SiliconANGLE 权威实录

谷歌有限责任公司的谷歌威胁情报小组今天发布的一份新报告发现，攻击者首次使用无人参与的人工智能框架将安全补丁转化为漏洞。

该框架名为exploit_agent，出现在一个暴露的临时服务器上，它被连接到几个前沿和本地托管的大型语言模型中。据 GTIG 称，其工作是在每个补丁发布前后持续比较流行的 Web 应用程序代码。一旦发现可能的缺陷，它所起草的漏洞就会自动执行。

从受害者那里获取的数据与暴力破解、安装 Webshel​​l 甚至删除竞争对手留下的 Webshel​​l 的脚本一起位于同一服务器上。受害者遥测表明，该运营商对与媒体、娱乐和教育相关的法国网站最感兴趣。该框架的配置文件中的一条注释是用俄语写的，告诉设置它的人“就在这里，而不是在聊天中”输入按键。

在两个月前的上一期季度跟踪报告中，GTIG 表示，它没有观察到针对野外目标部署的完全自主的攻击管道。根据题为“代理威胁活动跨越重大阈值”的新报告，这种情况在过去一个季度发生了变化。由于修补缺陷的源材料是有限的，GTIG 认为攻击者可能会发现让法学硕士针对 n 天漏洞比寻找 0 天漏洞更有效。

PaperCut Software Pty Ltd. 的打印管理服务器中存在两个缺陷，这两个缺陷相互关联并在 8 月下旬被作为零日漏洞利用，这说明了披露与有效利用之间的差距能够以多快的速度缩小。安全研究人员和 Huntress Labs Inc. 使用大型语言模型在披露后的一天内生成了有效的漏洞。

GreyNoise Intelligence Inc. 在披露四天后跟踪的一项活动据信是依靠法学硕士来构建其漏洞，然后才袭击数百个组织。 GreyNoise 发现，该活动的一个立足点在几分钟内就到达了域管理员。

在其他地方，开源代理渗透测试框架被用来自动化实时入侵的离散步骤。在一次针对美国航空航天领域的入侵中，观察到威胁行为者使用多代理框架 CAIRN。

另一位参与者在 8 月底到 10 月初期间运行了一个基于 PentAGI 构建的定制平台，以扫描亚洲的各种组织是否存在漏洞。目前，不受限制的自主执行留下的嘈杂的取证痕迹据说使框架更容易被检测到。

GTIG 表示，影响力运营现在使用模型的用途远远超出了撰写帖子的范围。一家商业承包商在 Gemini API 的帮助下构建了一个统包平台，该平台使用云电话农场，旨在运行超过 100,000 个社交媒体帐户。为了让生成的照片像智能手机拍摄的照片一样，一个单独的平台背后的提示据称要求故意制造相机缺陷，该平台针对整个欧洲和中东的政治情绪。

在政府支持的参与者中，一个被怀疑为 UNC6836 的朝鲜组织用来接触北美和欧洲的加密货币组织的虚假招聘人员资料中的照片被发现带有谷歌的 SynthID 水印。通过更改内部代码存储库中的 .claude/settings.json 文件，该组织后来操纵了 Anthropic PBC 的 Claude Code 的每次启动，以下载其 SOMBERMEME 后门。

谷歌表示，它已禁用与发现的 Gemini 滥用行为相关的账户和资产。谷歌 DeepMind 还利用这些发现来增强其分类器。

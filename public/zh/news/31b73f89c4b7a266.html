Anthropic强化MCP协议推动AI代理自治

✍️ 记者 / 供稿: Matthias Bastian

Anthropic宣布MCP标准月下载量超7亿，并新增后台任务与文件上传功能，大幅提升AI代理间协作能力

⚡ 核心要点提炼与关键事实

  • 【核心事件】Anthropic：MCP协议升级，新增后台任务与文件交互接口
  • 【起因与机理】满足AI代理处理多步骤任务、跨系统协同及降低上下文内存消耗的需求
  • 【关键数据与实测】核心规模：MCP SDK月下载量超7亿，连接器数量逾1万个。
  • 【各方立场与态度】技术优化：Tool Search按需加载机制使上下文占用率下降超85%。

📰 深度报道原文实录

THE DECODER 权威实录

Anthropic 报告称，其 MCP 标准推出两年后每月下载量超过 7 亿次。后台任务、用户跟进问题、文件上传等新功能旨在让克劳德更加独立地工作。

该公司表示，该标准的开发工具 (SDK) 每月下载量已超过 7 亿次，Claude 的 MCP 连接器下载量已超过 10,000 个。 Anthropic 正在扩展该协议，以便人工智能代理可以相互通信并更顺畅地协调工作流程。

“任务”和“启发”是最大的新增功能之一，在 10 月份的公开测试后正式上线。通过任务，服务器可以在后台运行更长的作业，并仅在结果准备就绪时才报告。启发可以让正在运行的进程暂停并询问用户特定的缺失细节。这两个功能都是为了让 MCP 服务器更加独立地运行。

人工智能代理很快就能将文件直接传递给外部服务

MCP 技能也是新的，目前处于公开测试阶段。该功能使服务器能够将他们的工具与技能相结合，指导克劳德完成长期、多步骤的任务。 Anthropic 表示，这些技能涵盖最佳实践、分步工作流程以及针对特定用户帐户或组织量身定制的说明。

该公司还宣布即将推出文件上传支持。发货后，Claude 将能够将 PDF、电子表格和图像等文件直接传递到 MCP 服务器。 Anthropic 计划很快在 Claude 和 Claude Code 中为 Pro、Max 和 Ultra 订阅者以及符合条件的团队和企业客户推出该功能。

技术变革为更大规模的 MCP 部署奠定了基础

这些新的代理功能建立在 Anthropic 在过去一年中所做的多项技术变革的基础上。为了减少活动对话期间的内存需求，工具搜索会等待加载各个工具描述，直到需要它们为止。 Anthropic 表示，这可以在多服务器设置中减少 85% 以上的上下文使用。

当前的 MCP 规范是无状态的，这意味着它不必永久存储会话数据。它适用于所有 Claude 产品。目标是让开发人员更容易构建服务器，并随着使用量的增长而更可靠地运行。

Anthropic 还为企业客户推出了企业托管身份验证。管理员可以一次性批准支持的服务器，以便员工自动连接。 MCP Apps 允许开发人员在 Claude 内部嵌入完整的用户界面，无论是在活动聊天旁边还是在全屏模式下。

2024 年 11 月，Anthropic 推出了模型上下文协议作为开放标准，使 AI 助手能够统一访问业务工具、开发环境和其他数据源。 OpenAI 首席执行官 Sam Altman 于 2025 年 3 月宣布，他的公司将在自己的产品中采用竞争对手的标准。 2025 年 5 月，OpenAI 使用远程 MCP 服务器升级了其 Responses API。上海人工智能实验室的研究人员使用 MCP 作为 2026 年 1 月推出的科学上下文协议 (SCP) 的模型。

🤖 雷达专属 AI 研判与技术透视

Anthropic试图通过MCP协议掌握AI代理生态的底层连接标准，将其从单纯的查询接口转化为支持长流程任务编排的自动化底座。此战略不仅增加了Claude在企业侧的用户粘性，更通过标准化协议试图构筑起AIAgent市场的通用互联壁垒。

Mount Thor获4500万美元融资建云平台

📖 阅读原资讯官网报道 ↗
初创公司Mount Thor完成4500万美元融资，旨在基于Apple Silicon芯片构建高性能云基础设施

⚡ 核心要点提炼与关键事实

  • 【核心事件】Mount Thor（云基础设施初创公司）在企业级云服务市场：完成4500万美元融资，提供基于Apple Silicon的云端macOS算力实例
  • 【起因与机理】满足AI代理与macOS生态内开发测试对高性能弹性硬件的迫切需求
  • 【关键数据与实测】获得4500万美元融资用于构建Apple Silicon云平台。
  • 【各方立场与态度】支持AI代理的持续训练、跨设备自动化及合规沙盒测试。

🤖 雷达专属 AI 研判与技术透视

Mount Thor切中了AI开发工具链的细分痛点，即Apple Silicon在本地端侧AI处理上的性能优势目前在云端存在基础设施真空。此举实质上是将macOS生态的算力资产化，为强化学习与跨设备AI代理部署提供了绕开传统虚拟化限制的裸金属级解决方案。

📰 深度报道原文实录

9to5Mac 权威实录

苹果芯片上的人工智能代理令人难以置信，而且没有人在数据中心规模上租用它们。

关于 Apple @ Work：Bradley Chambers 从 2009 年到 2021 年负责管理企业 IT 网络。通过他在部署和管理防火墙、交换机、移动设备管理系统、企业级 Wi-Fi、数千台 Mac 和数千台 iPad 方面的经验，Bradley 将重点介绍 Apple IT 经理部署 Apple 设备、构建支持它们的网络、培训用户的方式、IT 管理一线的故事，以及 Apple 为 IT 部门改进其产品的方式。

CRV 和 Conviction 共同领投了 A 轮融资。Chad Byers 和 Offline Ventures 共同领投了种子轮融资。 CSC Leasing、Enea Capital、Long Journey Ventures 和 Upper90 参与其中，还有来自 OpenAI、Meta、Cognition、Together AI 和 Vercel 的天使投资者。该公司还为新硬件筹集了单独的非稀释性融资。

Mount Thor 在 Apple 芯片上运行 macOS 作为弹性计算实例，就像云提供商租用 Linux 虚拟机一样。客户可以按需获得一组 Mac 来完成仅在 macOS 上进行的工作：在强化学习环境中训练计算机使用模型、为代理运行安全的 macOS 沙箱、让代理在一个 Apple ID 下跨用户设备工作的长期运行实例，以及为 Apple 软件构建和测试场。

有两种方法可以使用其解决方案。通过托管计算，客户可以选择机器类别和映像，并获得完整的裸机 Mac 或具有管理员访问权限的独立 macOS 虚拟机，通过 Web 门户、命令行工具、Kubernetes 或 API 进行配置，并按 24 小时按 Mac 计费。通过客户管理的计算，组织可以使用自己的 MDM 在 Mount Thor 站点运行自己的 Mac，而 Mount Thor 则运营该设施并按序列号提供库存、问题报告和事件通知。

争论的焦点是，客服人员正在成为 macOS 用户，而对苹果平台的需求现在随着客服人员的数量而不是人数的增加而增加。

Mount Thor 创始人兼首席执行官 Peter Voell 表示：“在数据中心规模上提供苹果操作系统和芯片是人工智能基础设施领域一个尚未开发的巨大机遇。” “数十年在可访问性和人机交互方面的投资使 macOS 成为智能体工作和人类追究其责任的最佳场所。借助 M5 Ultra 等芯片，Apple 芯片正在成为一个高性能、更省电且更具成本效益的生产推理平台。”

它的另一半内容是推理。 M5 Ultra Mac Studio 于 8 月份发货，配备高达 512GB 的统一内存，这使得大型开放式重量模型可以在单台机器上运行，而功耗只是传统的基于 GPU 的服务器的一小部分。 Mount Thor 表示，新资金的重点是在苹果芯片上建立所谓的最佳开源模型推理实验室。

CRV 普通合伙人 Brittany Walker 表示：“Mount Thor 处于两个重要转变的交汇点：自主代理功能的快速扩展以及对支持本地和云工作负载的计算需求的不断增长。” “我们很高兴能够支持 Peter 和他的团队，因为他们让大规模使用 Apple 平台实现代理 AI 变得更加容易。”

该团队来自 Cerebras、CoreWeave、Fluidstack、Nebius、OpenAI 和 xAI。该公司成立于今年，并在不到六个月的时间内部署了第一个数据中心。

云中的 Mac 并不新鲜，因为 AWS 租用 Mac 实例已经有几年了，而且 MacStadium 这样做的时间比 AWS 还要长。 Mount Thor 的主张是，更大的客户是需要 Mac 来完成工作的 AI 代理，并且这种需求随着代理数量而不是开发人员数量的增长而增长。

该公司表示，这笔资金将用于扩大其计算范围和建设团队，并计划快速增加容量以满足客户需求。

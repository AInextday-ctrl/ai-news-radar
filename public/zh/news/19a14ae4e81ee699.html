微软大规模替换第三方AI模型

✍️ 记者 / 供稿: Jonathan Kemper

微软AI事业部发布七款自研模型，旨在降低企业级AI代理的推理成本并优化性能

⚡ 核心要点提炼与关键事实

  • 【核心事件】微软AI事业部 (Microsoft AI)在微软Ignite大会：推出MAI Code 2等七款自研模型，替代第三方模型
  • 【起因与机理】降低企业级AI代理的高额token支出与运营成本
  • 【关键数据与实测】Microsoft charges $0.042 per million input tokens, or $0.05 in the EU data zone. Output tokens are free.。
  • 【各方立场与态度】微软通过生态内嵌手段重构AI业务盈利模式。

THE DECODER 权威实录

Microsoft AI (MAI) 的目标是始终在线的 AI 代理，提供新的代码、安全、图像、语音和路由模型。主要衡量标准是自己的合作伙伴OpenAI的阵容。

在 Ignite 大会上，MAI 推出了 7 款新车型，并以单批次的方式发布，而不是像 6 月份的 Build 大会那样分散在全年发布。微软对新产品系列的定位主要是性价比。该公司指出，希望全天候运行人工智能代理的客户的代币支出迅速增加。微软表示，其代码模型针对日常企业编码任务，尚未针对基础研究或长期代理工作流程等艰巨工作进行优化。

MAI Code 2 以促销价接近 GPT-6.1 Sol 和 Opus 5.5

据 Microsoft 称，MAI Code 2 在四个基准测试中平均达到 GPT-6.1 Sol 性能的 98%，而成本仅为 GPT-6.1 Sol 的 40%。与Claude Opus 5.5相比，它以5%的成本达到了96%的性能。 Microsoft 在 DeepSWE 1.1、Terminal Bench 2.1、SWE-Atlas 和 FrontierCode v1.1 上进行了测试。其中三个测试使用 GitHub Copilot CLI 在 Microsoft 的内部 MSBench 平台上运行，无需使用子代理。微软正在为其自己的型号计算 50% 的促销折扣。

微软表示，在对 UI、游戏、数据可视化和 SVG 图形等前端工作进行盲目比较时，人类评估者在 64% 的情况下更喜欢 MAI Code 2 的输出，而不是 GPT-6 Sol。

MAI-Code-1.1-Flash 的后续产品 MAI Code 2 Flash 专为代码解释、有针对性的编辑和常规修复而设计。据说它的成本相当于 GPT-6 Luna 和 Claude Haiku 5.5 的 65% 和 20%。

Microsoft 从 Flash 模型派生出 MAI Work Flash。它在 Microsoft 365 和 Fabric IQ 中运行。微软表示，在内部 Excel 和 PowerPoint 基准测试中，它与 GPT-6 Luna 相匹配。在 Word 中，它的性能与 GPT-6.1 Sol 类似，但消耗的输入令牌减少了约 42%。对于在 Power BI 中生成 DAX 查询，它的性能优于 GPT-5.6 Sol、GPT-6 Astra 和 Opus 5.5。

在 GitHub Copilot 中，截至 2027 年 5 月 17 日，MAI Code 2 的促销价格为每百万个输入代币 0.50 美元，每百万个输出代币 2.50 美元，然后为 1 美元和 5 美元。在此之前，MAI Code 2 Flash 的价格为 0.05 美元和 0.25 美元，分别上涨至 0.10 美元和 0.50 美元。

具有清理基准的安全模型

微软表示，MAI Cyber​​ 2 Flash 解决了 Cyber​​Gym-E2E 漏洞基准测试中 92.3% 的任务。 GPT-6 Astra 达到 91.5%，但需要两倍的推理预算。每个任务的 MAI 模型成本不到 GPT-6 Astra 的 2%，每个代币成本为百分之一。在 WebExploitBench 上，它的得分为 40.4%，领先于 GPT-5.6 Cyber​​ 的 38.4%。

在评估过程中，微软发现大约 900 个 Cyber​​Gym 任务中有 10% 利用相同的开源项目和漏洞报告作为其自己的训练数据的一部分。该公司表示，参考解决方案从未进入培训。无论如何，微软删除了所有模型的这些任务，只对其余的任务进行评分。

到目前为止，还缺少与 GPT-6 Cyber​​ 的比较。该型号仅适用于选定的客户。微软表示，使用工具进行代理基准测试仍然需要额外的安全措施。该公司计划在未来几周内公布这些结果。

上下文窗口跨越一百万个令牌，是 MAI Cyber​​ 1.1 Flash 大小的四倍。输出代币的成本比前代低 86%。新闻稿称，MAI Cyber​​ 模型已经处理了微软安全平台 MDASH 上近 40% 的扫描。

微软将 MAI Cyber​​ 2 Flash 的定价定为每百万输入代币 0.10 美元，每百万输出代币 0.50 美元，而 GPT-6 Astra 的定价为 10 美元和 50 美元。在 Cyber​​Gym-E2E 上，每项任务的费用为 0.45 美元，而不是 34.38 美元。

🤖 雷达专属 AI 研判与技术透视

微软此举标志着其从“模型分销商”向“全栈模型自给自足”的战略转型，直接威胁其合作伙伴OpenAI的市场空间。通过将自研模型内嵌至生态体系，微软完成了从算力基础设施到模型层的利润闭环，进一步压低了AI应用层的部署门槛。

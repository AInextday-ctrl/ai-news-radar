通常，我测试的产品不会帮助我写下我的使用体验。二重奏是不同的。

Claude Duet 是 Anthropic 面向消费者的人工智能代理，这是一家人工智能公司的最新尝试，试图让我们相信代理对于不编写代码的人来说也是有用的。这是有趣的几个月：Instinct 为我们提供了一个令人印象深刻的基于文本的助手，Meta 为我们提供了它可爱的小家伙 Muse，帮助我们购买东西，而 OpenAI 为我们提供了更以工作为导向的 Dots。克劳德·杜埃（Claude Duet）甚至比那些更专注于工作。它也比 Claude Cowork 更适合消费者，而 Claude Cowork 又比今年早些时候启动了整个炒作周期的编码代理 Claude Code 更适合消费者。过去一周，我在繁忙的旅行和工作日程中一直在测试它。有时它确实很有用，但又有点唠叨，而且非常渴望写下它自己。

与 Meta 的 Muse 一样，Duet 也有自己的应用程序。 （如果您在家记分，是的，它已经更新为完全支持 iPhone Duo）。 Duet 采用了克劳德特有的欢快、简约的设计。该应用程序对消费者友好且平易近人。一旦你连接了所有你想要的生产力和聊天服务，它就会寻找帮助的方法，并将它们建议为卡片，你可以向左或向右滑动来隐藏或接受——有点像 Tinder 的待办事项列表。

以测试的名义，我全力投入 Duet，并为它提供了一切：我的工作电子邮件、日历、Google Docs 和 Slack。这给工厂带来了比我一开始意识到的更多的好处。因为我们每两周一次的员工会议会自动总结在 Gemini 发送的电子邮件中，而 Duet 可以访问我的电子邮件，因此它能够将会议中所说的内容与 Slack 中的直接消息联系起来。 Duet 还找出了我的老板是谁，因为我们有一个共享的 Google 文档用于每周的 1:1 会议。当人工智能能够吸收大量数据时，它才是最有用的，而 Duet 没有浪费时间这样做。

Duet 每天早上都会向我发送一条简短的消息和一些当天的亮点，比如提醒我在起飞前收拾好拍摄视频所需的物品。下面，它会建议待办事项，通常以帮助起草消息或将项目添加到议程中的提议结束。

这通常很有帮助，尽管有时感觉就像是在与一个有点神经质的私人助理互动。有一次，我给采访过一篇报道的人发了一封电子邮件，称这篇文章可能会在周二发表，届时我会发送一个链接。周一深夜，我将草稿提交给编辑，而周二早上，Duet 就疯狂了。当时还不到上午 9 点，它指出这个故事仍在等待编辑，我需要继续编辑——否则我将无法发送我承诺的链接。这种担心有点多余。它没有注意到我的消息中的细微差别，暗示这不是一个硬性的截止日期，也没有注意到我的编辑现在只是当地时间早上 7 点这一事实。

在其他情况下，它却出奇地有帮助。在计划接下来的几周时，我忽略了这样一个事实：即将到来的休假只会让我在另一次重大选秀到期之前只剩下几个工作日。 Duet 提出了一个解决方案，提出为我的编辑提供每周更新 Google 文档的笔记，并为他起草了一条 Slack 消息来记录更新。读者，这个消息有点太好了。它复制了我千禧一代用小写字母书写的习惯——它在旁边稍微沾沾自喜地指出了这一点——并使用了我们经常用来指代我们的 CMS 的缩写。但它也将“signature”这个词缩短为“sig”，这是我永远不会做的，这让我笑出了声。无论如何，谁都骗不了； Slack 消息被标记为“与 Claude 一起发送”标签。

Duet 经常自愿帮助我开始草稿，这对我来说总是很难拒绝。我会写我自己的小博客，非常感谢克劳德。如果你不是作家，我可以看出，在这里或那里处理一些写作琐事会有多大帮助。但这开始感觉就像是蜘蛛侠指着蜘蛛侠的时刻，因为它想要帮助完成的任务正在自我审查。

这也有点不可思议。即使抛开我正在写 Duet 的事实，知道它可以阅读我发送的每封电子邮件、草稿和 Slack 也有点奇怪。它可以读取所有这些，因为我选择共享这些数据，并且我完全清楚自己在做什么。但在实践中看到它是另一回事。我想知道如果我知道我不需要负责将事情放在日历上、写下待办事项列表或在会议中集中注意力，因为 Duet 会处理这些事情，这是否会改变我的工作方式。也许这就是CEO的生活方式。并不是说我珍惜创建日历条目，但我想知道我最终是否会感到与工作场所有点脱节。

我不认为 Duet 或任何其他人工智能代理已经准备好让我们感觉我们都是自己小世界的首席执行官。 《私人助理》的标题中有一个关键词：个人。一个人可以通过语气的细微差别来理解什么是大事，什么是小事。一个人会掌握沟通规范并明智地运用它们。一个人可以很委婉。 Anthropic 的博客文章提到，该公司正在继续“测试其对何时向您发送消息的判断”，因此，随着时间的推移，Duet 可能会更好地进行校准。但总体而言，人工智能并不擅长理解细微差别或语气，而且目前还不清楚它是否会如此。

对我来说，Duet 让我更清楚地知道我希望人工智能为我做什么以及我不做什么。在现代工作场所中，沟通无处不在——通过电子邮件、私信、会议、共享文档。让人工智能发现所有这些来源之间被忽视的差异并主动指出它们确实很有帮助。我喜欢它作为我自己的组织系统的后盾，而不是替代它们。我不喜欢创作过程。就像，完全一样。正如汉克·格林谈到自己对人工智能的依赖时所说，我想找到“我自己的方式来进入和围绕一个主题”。如果你派一个机器人去跑腿，你就会错过偶然发现意想不到的事情的机会。这是使工作变得愉快的一部分。我当然不会让代理人为我自我审查。你听到了吗，二重奏？

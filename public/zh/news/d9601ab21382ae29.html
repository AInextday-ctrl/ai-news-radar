ZDNET 权威实录

您会让一些克劳德代理为您审查并发送您的代码吗？

开发人员已经在大量使用 Claude Code 和其他人工智能驱动的编码工具，例如 OpenAI 的 Codex，但有些人仍然希望在推送代码之前自行检查代码。 Anthropic 的一项新功能依赖于更具冒险精神、代理优先的编码人员能够轻松地将最后一步交给人工智能。

Anthropic 表示，通过周一宣布的测试版 Claude Ship，“Claude 现在可以审查拉取请求、修复它们，并批准团队政策允许的请求”。该功能面向那些想要更快地行动或已经将大量编码任务委托给代理的开发人员。

“团队可以控制它的运行位置以及哪些变化需要人，”Anthropic 说。 “目标：交付代码的速度与团队编写代码的速度一样快。”

新功能使用了两个新代理以及 Code Review，Anthropic 在 3 月份针对 Teams 和 Enterprise 计划发布了 Code Review。代码审查首先收集、组织调查结果并将其发布到 PR。然后，Anthropic 表示，PR Steward 和 Claude Approvals 等代理人“通过审查、修复和批准决定来指导 PR，这样团队就不必手动管理每个步骤”。

PR Steward 无法批准或合并拉取请求，而是旨在参与“失败的 CI 检查、合并冲突以及审查来自代码审查、其他审查工具或团队成员的反馈”。它还通过注释记录了每次推送中发生的更改，并提供了如何撤消它的说明（如果开发人员愿意的话）。在整个过程中，开发人员可以向 Claude 发出指示，或者通过评论 @claude 来告诉它停止。

作为最后一步，Claude Approvals 会参考团队遵守的任何政策（开发人员以存储库文件的形式提供）以及开发人员设置的其他信号（例如代码审查结果），然后在允许的情况下自主批准更改。 Anthropic 表示，如果没有，它将寻求“更深入的人类签字”。

“它的工作原理就像一个更智能的 CODEOWNERS 文件，”该新闻稿补充道。 Anthropic 表示，它建议大多数客户“首先在仅观察模式下启用这些额外检查，以在配置分支保护以要求 Claude Approvals 开绿灯之前建立信心”。

管理员可以选择该功能在哪个存储库中运行，并根据需要调整设置。

但克劳德·希普并不适合所有人。

Anthropic 在新闻稿中表示：“大多数团队都希望有人批准每一项更改，而且当人们编写每一行代码时，这很容易跟上。但现在很多开发人员都使用代理进行构建。”他指出，其自己的 Claude Code 团队使用 Claude 来编写其所需的大部分代码。

ZDNET 高级特约编辑 David Gewirtz 表示，以编写代码的速度交付代码的想法“让我感到毛骨悚然”。但他补充说，鉴于 Claude Code 迄今为止令人印象深刻，如果 Anthropic 的部署工具同样有效，他不会感到惊讶。

“但是，这确实取决于团队的工作流程以及他们正在进行的开发类型，”他说。 “这并不适合每个团队，当然也不适合每个独立开发人员，但对于某些部署流程来说，它可以节省大量周转时间，节省资金，并可能更快地向客户发送修复程序。这很酷。”

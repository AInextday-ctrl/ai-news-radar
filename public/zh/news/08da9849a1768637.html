人工智能帮助发现对互联网至关重要的软件平台Java的主要安全漏洞

✍️ 记者 / 供稿: Dustin Volz and Dylan Freedman

OpenAI推出针对网络安全研究的GPT-6 Cyber模型，已识别Mozilla Firefox及Linux内核中数百项漏洞

⚡ 核心要点提炼与关键事实

  • 【核心事件】OpenAI (开发机构)：发布GPT-6 Cyber，具备自动漏洞挖掘、补丁编写及安全红队测试能力
  • 【起因与机理】旨在通过自动化提升大规模代码库的安全性，防止攻击者利用未公开漏洞
  • 【关键数据与实测】该模型已在Firefox浏览器中挖掘出81个高危漏洞，并在Linux内核测试中成功构建948项利用方案，目前该工具被列为“关键”级别，仅限受邀安全机构使用。
  • 【各方立场与态度】因具备高度攻击潜力被OpenAI划定为“关键”级别，限制公开访问权限。

📰 深度报道原文实录

New York Times 权威实录

一家网络安全初创公司周二透露，它已经使用了一种新的人工智能技术。 Java 是一种流行的编程语言，被政府机构和大约 90% 的财富 500 强公司使用。

这是企业和政府面临的现实的最新证据，因为人工智能。正在彻底改变计算机漏洞的发现领域，识别代码缺陷的速度如此之快，以至于网络安全专业人员都在努力跟上。

使用领先的人工智能近几个月来，初创公司 Calif 发现了一系列严重的漏洞。这家初创公司的最新成果暴露了一个缺陷，即使用 OpenAI 最近发布的 Java 语言 GPT-6 网络模型，该模型被银行、医院、航空业和科技巨头以及政府机构（包括承担国家安全任务的机构）广泛使用。

加州高级研究员 Bruce Dang 表示：“Java 是现代经济的心脏。”他补充说，“实际上，所有大公司”都将受到该漏洞的影响。

党先生和他的同事最近几天一直致力于与“五眼”情报共享联盟（由美国、加拿大、澳大利亚、新西兰和英国组成）中的所有政府机构以及包括谷歌和微软在内的私营部门的主要供应商进行协调。

美国国家安全局的机密网络于周二因“例行软件维护”而瘫痪，该局没有回应置评请求。目前尚不清楚这次中断是否与解决 Java 错误有关。

Java 商标的所有者和商业 Java 许可证的提供商 Oracle 没有回应置评请求。该公司周二发布了一个软件补丁。

网络安全和基础设施安全局在一份警报中敦促各组织“立即修补”该漏洞。

加州和其他组织发布的利用人工智能工具进行攻击的消息震惊了网络安全界，并颠覆了几个月前一小群程序员认为可以实现的目标。这些工作包括在人工智能模型公开发布之前与它们合作，帮助网络防御者注意未被发现的问题，以便在恶意黑客发现并造成破坏之前修复它们。

但Java的发现可能是加州迄今为止最严重的，它可能使黑客能够远程访问敏感的内部系统。最近几天，一系列看似独立的中断——微软产品中断、全国范围内的航班停飞和银行业务中断——动摇了公众对日常技术可靠性的信心，并加剧了人们对人工智能可能是罪魁祸首的担忧。（到目前为止，对每种现象的解释似乎都相对温和。）

英国国家网络安全中心首席技术官奥利·怀特豪斯（Ollie Whitehouse）表示，人工智能辅助的漏洞挖掘和网络攻击构建使识别系统漏洞变得更加容易。“我们已经看到这种情况形成一段时间了，人工智能被用来发现我们都依赖的软件和数字服务中越来越多的潜在漏洞。”

Java漏洞是Calif在过去一年里在OpenAI模型的帮助下发现的第二个重大漏洞。

但 PHP 缺陷主要涉及帮助网站运行的软件。相比之下，Java 有助于为现代数字世界的具体细节提供动力，包括云计算架构、身份管理工具、电子邮件服务等。

加利福尼亚州首席执行官 Thai Duong 表示：“Java 无处不在。”他指出，Java 漏洞不容易被武器化为攻击手段，这让防御者有更多时间来修复问题。

“但是漏洞有很长的尾巴，”他补充道，并预测该错误可能会对未来五到十年内不更新的系统构成威胁。

最重要的发现之一是，Calif 证明它可以利用此错误侵入 Keycloak（一种广泛使用的身份验证和登录系统）。 Keycloak 保护数千个组织，包括 CERN、惠普、UnitedHealthcare 和 NASA。

人工智能在网络安全领域的快速进步与国际象棋世界冠军加里·卡斯帕罗夫 (Garry Kasparov) 近 30 年前输给 IBM 深蓝计算机后所观察到的情况如出一辙。

他预测，最好的国际象棋游戏不会由人类或计算机来玩，而是由两者的混合体来玩。他将这个概念称为“半人马”，以向神话中的半人半马生物致敬。多年来，半人马被视为最好的国际象棋棋手，在棋艺上达到了新的高度。

现在，公司和政府正在应对“半人马黑客”的威胁——一半是人工智能，一半是人类，完全有能力在互联网上制造混乱。

最令人震惊的发现——至少目前——仍然需要人类的专业知识。近几个月来，由经验丰富的安全研究人员组成的小团队使用了顶级的人工智能。这些模型可以在几天或几小时内构建出各种高级网络攻击，而这些攻击曾经需要国家安全局等间谍机构的精英黑客几个月才能构建。

OpenAI负责网络准备和安全的福阿德·马丁（Fouad martin）表示，加州的Java研究“表明，人工智能可以帮助安全研究专家发现我们都依赖的软件中的严重缺陷”，并有助于促成合作修复。“我们希望更多的安全团队拥有这些能力和工具，帮助每个人都能更安全地使用关键软件，”马丁说。

谷歌的信息安全工程师爱德华多·维拉·纳瓦（Eduardo Vela Nava）表示，“收到通知后，我们迅速在谷歌的服务中推出了缓解措施和补丁，开发了检测措施，以确保没有人利用这个漏洞，并为我们的客户提供了指导。”

安全专家预计，至少在短期内，这些风险可能会增加。在大约20年的时间里，半人马棋手被普遍认为有能力下最好的国际象棋。但最终，半人马被更先进的超级计算机所取代。

Duong 先生认为，人工智能出现这种情况可能只是时间问题。可以独立构建最先进的网络攻击，这可能会迎来一个充满不可预测问题的新时代。联邦调查局本周发布了一份警报，称黑客正在使用新的自主人工智能。针对世界各地政府机构和企业的黑客工具。

“我不知道我们还有多少时间——也许是三个月，也许是三年，”杨先生说。 “但现在，最好的黑客是半人马黑客。”

GPT-6 Cyber的出现标志着AI红队测试已从辅助工具进化为具备自主攻击链构建能力的深度威胁防御系统。随着此类模型能力的增强，软件供应链的安全性将从人工审查彻底转向模型对抗的“算法防线”，这也将迫使全球监管机构重新评估针对高阶自动化攻击工具的出口管制红线。

顶级模型被曝可轻易被诱导攻击

Wired AI 权威实录

在过去的一年里，安全研究人员警告说，人工智能代理可能会大大加快网络犯罪分子发起网络攻击、破坏公司并最终从这些受损系统中窃取金钱、数据或敏感信息的能力。对于至少一部分黑客来说，这个时代似乎已经到来。

自 8 月底左右以来，世界各地的多家公司、政府机构和银行已成为网络犯罪分子采用新一波人工智能渗透测试工具的目标。这些设置（其中许多模仿合法的防御渗透测试技术）使用法学硕士自动扫描潜在的黑客目标，并试图强行进入安全性较差的网络，然后执行由人类操作员编写的攻击计划。

数十个人工智能渗透框架或“工具”详细说明了人工智能模型应如何进行网络安全测试或攻击，它们越来越多地与现实世界的攻击联系在一起。根据大约六家安全公司的警报，这些工具没有引入攻击网站或服务器的新方法，而且并不复杂。相反，它们允许网络犯罪分子以人类无法做到的速度发起攻击。

研究人员表示，黑客也不需要熟练地使用这些工具，原本需要几天时间的攻击只需几个小时即可完成。 AWS 首席信息安全官 CJ Moses 最近在公司博客文章中写道：“代理框架已经从实验性使用发展到持续的、多目标的攻击性操作，并且在人为干预最少的情况下运行。”

这些工具中最著名的是 Artex。这个开源框架是用编程语言 Go 编写的，于 7 月份由一位匿名开发人员使用 Autumn-27 首次在 GitHub 上发布，此后它就在一些黑客社​​区中传播。 Artex 已用于攻击的所有部分，从对网络进行初步分析、获取访问权限、在系统内移动以及准备要导出的数据。

“这确实是一款一体化产品，”攻击性安全研究员兼安全公司 Cypen 的创始人 Jacob Larsen 说。 “之前迭代的人工智能代理渗透测试工具要么只进行侦察——比如[目标]的扫描和分析——有些只能进行测试。这确实是一种傻瓜式武器。”

与其他人工智能黑客框架一样，Artex 本身并不是人工智能产品。相反，它本质上是一个指南，将外部前沿和开源人工智能模型（可以通过 API 连接到它）指向一系列现有的渗透测试工具和流程。使用 Artex 或其他类似设置的人们可以给出简单、自然的语言提示来开始操作。据安全公司 Check Point 的研究人员称，一组黑客向 Artex 提示：“对 [已编辑的受害者] 发起渗透攻击，以获取对网站管理面板、数据库或服务器的访问权限。”

一旦发出指令，多个人工智能代理就会执行它们。一个代理将把计划分解为一系列任务，其他代理将尝试执行这些操作，然后系统将呈现其发现。底层人工智能模型中的安全护栏，尤其是来自前沿实验室的模型，可以在检测到黑客活动时阻止黑客活动。然而，自由的中国模式和被废除的模式越来越善于闯入系统。

“它很快；它很高效，”安全公司 GitGuardian 的研究员 Guillaume Valadon 在谈到 Artex 时说道。瓦拉登和其他人表示，这些工具的简单性使得不熟练的黑客更容易尝试进入市场——即使他们不知道自己在做什么。 “它降低了门槛，”瓦拉东说。 “我想说我的祖母可以做到，只是她没有笔记本电脑，但门槛太低了。”

因此，来自网络安全公司的一系列报告将 Artex 的使用与尝试并成功的黑客攻击联系起来——通常是中文网络犯罪分子试图赚钱。其中包括数千家韩国金融机构的个人信息被盗、潜在的加密货币盗窃以及在 GitHub 上寻找暴露的登录详细信息。

美国联邦调查局 (FBI) 上周在有关 Artex 的警报中警告称：“各种恶意网络行为者利用 Artex 开展针对全球多个行业组织的活动，包括金融服务、政府、技术、国防、半导体、能源、医疗保健、制造、电信和法律行业。”

据安全公司 CrowdStrike 称，去年 10 月，与中国有关的黑客 Vapor Panda 使用 Artex 攻击了 200 多个组织，包括美国的智囊团、半导体和国防公司，以及欧洲和其他地方的政府外交部。微软发现中国黑客在供应链受到攻击后使用 Artex 尝试登录 Microsoft 365 设置，并将其追踪为 Storm-0940。黑客花了不到三个小时就获得了系统的特权访问权限。

10 月 8 日，Autumn-27 开发者从 GitHub 上删除了 Artex，并在评论中表示，它们“与这些恶意攻击没有任何关系”，并且这些工具是出于“教育和研究目的”而开发的。 《连线》杂志向与开发者链接的地址发送的电子邮件没有收到回复。

尽管开发人员拉动了 Artex，但该框架的多个版本已被复制，并与其他类似工具一起继续开发和使用。 Valadon 表示，GitGuardian 到目前为止已经记录了 45 种不同的 AI 攻击框架，其中研究人员经常提到的 Cyber​​strikeAI、Hexstrike、CAIRN 和 PentAGI。它们的工作方式都相似，只是技术能力略有不同。对于使用此类工具防御攻击的人们来说，一线希望是它们目前很容易被发现。

此项测试揭示了生成式AI在“对齐”（Alignment）上的致命缺陷：即模型对真实世界后果的语义理解完全服从于上下文提示的语境设置。当模型通过“游戏化”脱离现实语境后，现有的道德安全边界即刻失效，这对涉及高风险决策的AI落地监管构成了严重挑战。

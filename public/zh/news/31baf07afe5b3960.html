Copilot 是“新的工作操作系统”，现在 Office 在其中运行

✍️ 记者 / 供稿: Nick Indge

微软在Ignite大会宣布Office三件套深度集成至Copilot，并推出具备自主代理能力的Copilot Autopilot及组织智能平台Work IQ

⚡ 核心要点提炼与关键事实

  • 【核心事件】微软首席执行官萨提亚·纳德拉在微软Ignite大会：Office应用内嵌至Copilot，并发布Copilot Autopilot自主代理与Work IQ平台
  • 【起因与机理】将传统工具转变为AI Agent的支撑层，实现自动化生产力闭环
  • 【关键技术规格】核心产品形态重构：Office应用成为AI Agent的后端插件，实现从工具到服务的范式转移。
  • 【涉及范围与推进】市场与合规节点：商业定价将基于Copilot Credits使用量，企业需通过内部IT合规性评估以开放数据权限。

📰 深度报道原文实录

Ars Technica 权威实录

微软首席执行官萨蒂亚·纳德拉在Ignite大会的主旨演讲开场时，阐述了公司对其全新“前沿生态系统”的愿景，并于周二宣布Word、Excel和PowerPoint在Copilot中的正式上线，他将Copilot描述为“全新的工作操作系统”。

这一公告与我们传统上使用软件的方式截然相反。微软设想的新版Copilot集成不再是像Word这样的应用程序成为亮点，而Clippy则作为助手帮助您使用它，而是……

关于代理商的一切

根据微软的说法，Copilot Autopilot（不要与 Windows Autopilot 混淆）是“持久、主动的个人生产力代理”。简而言之，Autopilot 是一个基于云的自主人工智能代理，用户可以将职责委派给它，而不仅仅是单个任务。 Autopilot 可以被授权跨电子邮件和日历等服务工作，并完成分配给它的任务，作为其角色的一部分。 Autopilot 将通过 Copilot Credits 使用基于使用情况的计费，但最终定价尚未在全面上市之前公布。

主题演讲中还宣布全面推出 Microsoft IQ，这是一个包含 Work IQ 的智能平台，Work IQ 是一个上下文层，可帮助代理了解公司的通信、关系和正在进行的工作。纳德拉将工作智商描述为也许是公司最有价值的数据库：“它对人、他们与其他人的关系、你的电子邮件、你的会议、聊天、构成工作所有结构的项目有深入的了解。”公司是否希望自主代理能够访问内部文档和消息传递数据必须由他们自己的内部 IT 审查决定。

Copilot Workspaces 是一种协作环境，目前可通过 Microsoft Frontier 早期访问计划获得，但很快就能将个人 Autopilot 代理引入 Workspaces。在主题演讲的早期，纳德拉表示，“到目前为止，人工智能交互大多是单人游戏。工作空间使其成为真正的多人游戏体验，人们和代理在共享背景下朝着共同的目标前进。”

信任是微软新前沿生态系统的第三个支柱，纳德拉在演讲中继续提到这一点，但方式却出乎一些人的预料。 “我们发现自己处于一个难以捉摸的境地。对这些模型的机械理解也难以捉摸。问题是：你怎么能相信所有这些强大的技术？现实是，根据定义，你不能，”他说。

纳德拉与“人工智能是魔法”的企业炒作情绪的规范背道而驰，他承认人工智能思维过程的内部运作仍然难以理解，而且无论模型的答案是否准确，都不能相信模型能够自我管理。纳德拉将该解决方案描述为“将情报供应与授予的权限分开的架构上的必要条件”。微软表示，每个 Autopilot 代理都会有一个唯一的 ID，管理员可以限制权限或完全阻止它。所有代理活动都会被记录下来以供人工审核，并且 Autopilot 可以在执行某些操作之前请求人工批准。

承诺的代理控制和承认人工智能系统并不总是值得信任是有意义的，但微软要求企业和用户转而信任公司自己的防护措施，尽管这些防护措施针对错误、流氓行为或数据泄露的有效性仍需证明。在微软看来，解决不可信情报问题的方法不是让人工智能代理变得值得信赖，而是控制他们被允许做的事情。企业必须决定将多少自主权委托给代理商。

除了护栏之外，微软还宣布了所谓的“人工智能透明度倡议”。该项目已与 Adob​​e 和 Mastercard 等 40 多家大公司合作，为人工智能治理和安全制定开放的全行业标准。纳德拉将该倡议描述为行业“帮助建立开放标准，使人工智能更安全、更透明、更容易获得”的一种方式。

关注和衡量代币支出

除了宣布的其他功能外，微软还宣布扩展 Agent 365 的功能，Agent 365 是其现有的控制平面，用于跨企业环境管理 AI 代理。新的特工警长将现有的身份、安全和管理系统扩展到人工智能 智能体。微软将目标描述为“在堆栈的每一层提供可观察性”。 Agent 365 提供对代理行为的治理控制，微软称其“执行自主，但有界和监督”。

与 Agent 365 一起推出的还有 Agent 365 业务分析：“您可以简单地将其视为人工智能使用的 ERP 系统。您可以准确地看到推动支出的因素，并将支出与推动业务价值的结果联系起来。”纳德拉说道。客户将能够看到与人工智能代币支出相关的实际成本，并将这些指标与所执行工作的价值进行比较。微软承认，辅助工作时间的估计是由模型确定的，而不是对可能节省的时间的直接测量。当企业评估人工智能实施是否会带来投资回报时，这是微软做出的一个有说服力的让步，但根据微软商业业务首席执行官 Judson Althoff 的说法，“任何你能用 Claude 或 ChatGPT 做的事情，你都可以用 Copilot 做得更好，而且成本更低。”

纳德拉仅简要承认上周的服务中断，导致全球用户对 Exchange Online 和 Teams 等服务的访问中断。 “上周提醒人们，数字基础设施作为世界的拨号音是多么重要，”他说。 “我们知道您对我们服务的信任，并非常认真地对待这一责任，在这种情况下，我知道我们还有很多工作要做。”

这种说法一直是房间里的大象，但微软确实通过强调之前讨论的“社区优先的人工智能基础设施计划”，似乎承认了公众对数据中心项目日益增长的担忧。在微软现有基础设施受到更严格审查的情况下，要求组织向软件代理提供更多自主权的演讲并不令人意外。

🤖 雷达专属 AI 研判与技术透视

微软通过将Office应用降维为Copilot的“插件”组件，实质上完成了从软件订阅制向基于AI Agent调用量的价值链重构。Work IQ通过对企业内部非结构化数据的摄取，形成了极高的迁移壁垒，迫使企业IT部门在生产力效率与核心知识产权安全边界之间进行博弈。

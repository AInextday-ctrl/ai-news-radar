OpenAI upgrades ChatGPT and Codex with new GPT-6.2 Astra and Sol models

✍️ 记者 / 供稿: Zac Hall

OpenAI 在 9 月份与 Astra 一起启动了 GPT-6 一代，然后在几周后的 DevDay 上将 Sol 升级到了 GPT-6.1。今天，GPT-6.2 Astra 和 GPT-6.2 Sol 将一起来到 ChatGPT Work 和 Codex。 OpenAI 表示，两者都可以用更少的输出令牌完成要求较高的任务，因此您可以在完成任务之前完成更多工作

  • 【核心事件】OpenAI 官方团队在全球社交网络与AI增值服务商业化市场：GPT-6.2 Astra 的输入成本为 8/100 万美元，输出代币为 40/100 万美元，比 GPT-6 Astra 下降了 20%； GPT-6.2 Sol 保持 GPT-6.1 Sol 的 2/100 万美元输入和 10/100 万美元输出代币定价

9to5Mac 权威实录

OpenAI 在 9 月份与 Astra 一起启动了 GPT-6 一代，然后在几周后的 DevDay 上将 Sol 升级到了 GPT-6.1。

今天，GPT-6.2 Astra 和 GPT-6.2 Sol 将一起来到 ChatGPT Work 和 Codex。 OpenAI 表示，两者都可以用更少的输出令牌完成要求较高的任务，因此您可以在达到使用限制之前完成更多工作。

GPT-6.2 Astra 和 Sol 有哪些新功能？

Astra 仍然是 OpenAI 为您最困难的项目推荐的模型。

假设您有一张幻灯片的屏幕截图，并希望演示文稿的其余部分看起来像它。 OpenAI 表示，GPT-6.2 Astra 可以使用该屏幕截图作为模板，并匹配布局、颜色甚至字体大小。

在 Codex 方面，OpenAI 表示 Astra 更擅长在现有项目中进行更改和测试。

“早期测试人员报告了更清晰的代码风格和更集中的测试，并且修改次数更少，”OpenAI 表示。

Sol 是日常编码和写作更实惠的模型，并且在一项编码测试中它与 Astra 惊人地接近。

Cognition 的 FrontierCode 2.0 衡量对实际代码库的更改是否足以让维护者进行合并。

OpenAI 表示，在两种模型都发挥最大推理能力的情况下，Sol 与 Astra 的差距只有半个百分点，而成本约为 Astra 的五分之一。

“你们中的一些人一直在非常礼貌地询问。你们中的一些人刚刚询问过。GPT-6.2 Astra 和 Sol 现已推出。超级高效，专为在重要的地方（现实世界）执行而设计。” — OpenAI (@OpenAI)

从今天开始，这两种模型均可在 Plus、Pro、Enterprise 和 Edu 上的 ChatGPT Work 和 Codex 中使用。

每月 200 美元的 Pro 计划还首次通过 Sol 获得超快模式。每月 500 美元的 Pro 计划在两种型号上都可以实现超快，一旦管理员启用，符合资格的 Enterprise 和 Edu 工作区也是如此。

超快有多快？ OpenAI 表示，尽管它使用了更多的配额，但它可以在任一模型上以标准速率的 4.5 倍生成代币。您可以从模型选择器切换速度。

如今，开发人员也可以通过 API 使用这两种模型。 Astra 的标准输入和输出价格比 GPT-6 Astra 低 20%，而 Sol 保持其 GPT-6.1 定价。

您可以在 OpenAI 的完整公告中阅读更多内容。

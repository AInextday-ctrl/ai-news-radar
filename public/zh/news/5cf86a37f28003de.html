谷歌发布决策API，赋能多模态自动化判断

📖 阅读原资讯官网报道 ↗
谷歌推出Gemini决策API，支持对复杂内容进行批量概率化判断，定价仅为每百万输入Token 0.1美元

⚡ 核心要点提炼与关键事实

  • 【核心事件】谷歌在谷歌人工智能工作室：发布Gemini决策API，支持对1000个预定义问题进行多模态概率评估，定价0.1美元/百万Token
  • 【起因与机理】降低自动化决策成本，解决复杂任务流中的路由与合规判断效率问题
  • 【关键数据与实测】该工具支持文本、图像、音视频及PDF等多模态输入，能够处理最多1000个评估问题并给出置信度得分，旨在满足企业在工具路由、内容合规与政策检查等场景下的自动化需求。
  • 【各方立场与态度】低成本定价意在抢占自动化决策与合规检查市场。

🤖 雷达专属 AI 研判与技术透视

谷歌终于发现比起让大模型写诗，企业更需要的是一个能自动干杂活的廉价“质检员”。这本质上是把AI从“艺术创作者”贬为“流水线工头”，毕竟在这个内卷时代，省钱做决策比展示幻觉更有市场。

Google 权威实录

隆重推出 Gemini Decisions API，由我们新的 Gemini Decision 1 模型提供支持。在文本、图像、音频、视频和 PDF 中快速、单次评估多达 1,000 个是/否、选择和评分问题。

我们推出 Gemini Decisions API，帮助您在文本、图像、音频、视频和 PDF 中做出快速、概率性的选择。该工具一次计算多个问题的置信度分数，提供一种经济高效的方式来路由查询、对内容进行评分或检查策略规则。您今天可以通过访问 Google AI Studio 中的 API 密钥并查看我们的 Python、JavaScript 和 REST 指南文档来开始构建。

今天，我们将推出 Gemini Decisions API，这是一个新的端点，用于快速、闭集决策，由我们的新 Gemini Decision 1 模型 (gemini-decision-1) 提供支持，可通过 Google AI Studio 中的 Gemini API 获取。

Decisions API 为您提供了专门构建的原语，用于有界选择，例如工具选择、策略检查、模型路由和上下文分级。您可以跨文本、图像、音频、视频和 PDF（最多 256K 个标记）传递一个多模式输入以及最多 1,000 个独立问题。 Gemini Decision 1 不是按令牌生成答案文本令牌，而是在一次前向传递中对候选选项进行评分，以每 100 万个输入令牌 0.10 美元的价格在 150-250 毫秒的端到端延迟内返回概率和置信度分数，输出令牌计费为零。

在涵盖代理路由、推理、排名和多模式理解的基准测试中，Gemini Decision 1 在整个套件中处于领先地位，并且校准误差最低。

Gemini Decision 1 对选项进行评分，无需逐个令牌解码，在多模式输入和多达 16K 个令牌的上下文中，模型计算的中值延迟保持在 50-100 毫秒（端到端 150-250 毫秒），每个请求 1 到 100 个问题几乎保持不变。由于输出代币为零，带有决策 API 的 Gemini Decision 1 在整个共享基准套件中的价格比带有交互 API 的 Gemini 3.5 Flash-Lite 便宜近 5 倍。

Gemini Decision 1 基于 Gemini 的本机多模式架构构建，可以在一次前向传递中直接处理文本、图像、音频、视频和 PDF。您可以将各种模式组合到一个共享输入中，例如将通话录音与帐户元数据配对，或将扫描的 PDF 索赔与损坏照片配对，并调整图像和视频输入的分辨率以控制视觉细节和令牌成本。

您可以在单个请求中针对共享输入评估多个问题，混合是/否检查、多项选择和评分标准。每个答案都包含一个置信度分数（从 0 到 1），因此您的代码可以将不明确的案例路由给后备或人工审阅者：

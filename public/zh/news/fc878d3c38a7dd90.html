阿里发布Qwen4-Max，架构革新实现算力成本缩减

✍️ 记者 / 供稿: Jonathan Kemper

阿里巴巴推出Qwen4-Max混合专家模型，通过四层注意力压缩及动态门控架构，显著提升推理效率并大幅降低任务成本

⚡ 核心要点提炼与关键事实

  • 【核心事件】阿里巴巴大模型团队：发布Qwen4-Max模型，引入新型上下文压缩与动态门控架构
  • 【起因与机理】应对大模型长文本处理的高昂计算成本与推理效率瓶颈
  • 【关键数据与实测】核心模型架构：2.4万亿总参数/710亿激活参数的MoE架构。
  • 【各方立场与态度】性能表现：Work360基准下任务成本下降62%，推理效率显著优于前代产品。

📰 深度报道原文实录

THE DECODER 权威实录

Qwen4-Max 是阿里巴巴对 Opus 5.5、GPT-6 和 Kimi K3.1 Pro 的回应。新的旗舰产品结合了更高效的架构和更低的价格，面向工业、科学和金融领域的专业工作。

据 Qwen 团队称，专家混合模型有 2.4 万亿个参数，但每个代币仅激活 710 亿个参数。它本机处理图像并提供一百万个令牌上下文窗口。

混合架构使长上下文的处理成本更低

Qwen4-Max 首次推出了 Qwen4 系列的改进架构。阿里巴巴并没有仅仅依赖标准的注意力层，而是结合了两种方法。三层将先前的上下文压缩为压缩状态，然后第四层仅挑选出重要的部分。这大大降低了长输入的计算成本，因为模型不再需要给予上下文的每个部分同等的关注。

该架构还在模型层之间添加了四个并行连接，动态门旨在稳定信息流。具有 3280 亿个参数的 N-gram 嵌入层提供通用标记序列作为现成的构建块。据阿里巴巴介绍，2.4万亿参数配置的训练运行稳定。在整个跑步过程中，训练损失稳步下降，没有突然上升。

阿里巴巴的内部评估以每字节位数衡量知识、代码、问答和 STEM 方面的模型质量。 Qwen4-Max-Base 在测试的五个检查点中得分最高。它比 Qwen3.8-Max-Base 提高了 5% 到 13%，同时每个令牌激活的参数减少了 25%。

较低的代币使用量可将每项任务的成本降低一半以上

效率的提高体现在运营成本上。 Work360是阿里巴巴自己的行业工作任务标杆，涵盖721个专业领域。在其上，Qwen4-Max 解决相同任务时使用的令牌比其前身少大约四分之一到三分之一。在代理基准 Terminal-Bench 4.0 上，令牌使用量下降了近一半。

据阿里巴巴称，每个 Work360 任务的平均成本下降了 62%，从 4.43 美元降至 1.67 美元。基准分数同时从47.74攀升至52.69。

外部基准的结果好坏参半。在 Agents' Last Exam v1.1 等长期代理任务中，Qwen4-Max 得分为 46.7 分，是对照组中的最佳成绩。它在人类最后考试中落后于 Opus 5.5 和 GPT 模型。在 HealthBench Professional 上，它落后于 GPT 模型，但略高于 Opus 5.5。

Qwen4-Max在中国车型中排名第二，成本仅为其前身的三分之一

在最高推理设置下，Qwen4-Max 在当前的人工智能分析智能指数中得分为 43 分。这比 Qwen3.8-Max 多了 9 分，比中国排名第一的 Kimi K3.1 Pro 低了 3 分（46 分）。与前身相比，涨幅最大的是 HLE-Diamond（上升 21 个百分点，达到 45%）、AA-Omniscience（上升 18）和 AutomationBench-AA（上升 17）。

人工分析显示，Qwen4-Max 每项智力指数任务的成本为 3.27 美元。这大约是 Qwen3.8-Max 售价 10.02 美元的三分之一，比 Kimi K3.1 Pro 的 3.68 美元便宜约 11%。节省的资金来自三个地方。令牌价格比前身低 25%，缓存命中成本降低 70%，并且该模型消耗的令牌更少。 Qwen4-Max 每个基准测试任务需要大约 105,000 个输出令牌，而 Qwen3.8-Max 需要 171,000 个。

腾讯的 Hy4 便宜得多，每任务 1.03 美元，但该指数得分低 8 分。在 Terminal-Bench 4.0 上，Qwen4-Max 得分为 48%，落后于 Kimi K3.1 Pro 的 67%。在 Cognition 的编码基准 FrontierCode 2.0 上，它与 Kimi 持平，为 26%，落后于腾讯 Hy4，为 31%。

通过自己的 API，阿里巴巴对每百万个输入代币收取 1.50 美元的费用，对每百万个输出代币收取 4.50 美元的费用。缓存命中成本为 0.075 美元。

Live Delivery 将长期运行代理的控制权交还给用户

与人工智能行业的许多公司一样，阿里巴巴围绕能够自行处理长时间任务的代理构建了此版本。如果用户只在最后看到结果，他们几乎没有办法修复错误。阿里巴巴的答案是“实时交付”。该模型尽早交付可用的第一个版本，并在以后的过程中构建它。用户可以随时介入并改变路线。阿里巴巴开源了配套的 Qwen-Live-Delivery-Plugin。

阿里巴巴列举了多个合作伙伴的部署情况。据报道，汽车合作伙伴 SANF 和 Pacific Union 使用 Qwen4-Max 将单个工件的手动编程时间从约 475 分钟缩短至 24 分钟。在金融领域，该模型利用 90 个 MCP 工具从多个来源提取市场数据。它将结果作为可验证的 Excel 和 PowerPoint 文件提供，并且每个数字都可以追溯到其原始来源。

阿里巴巴还在内部使用该模型来更有效地运行自己的云基础设施。据该公司称，Qwen4-Max 与内部求解器 MindOpt 合作，将数据注释的计算作业分配成本平均降低了 10.42%。当在数据中心分配CPU任务时，它找到最佳解决方案的速度比比较方法快14倍以上。

阿里巴巴的模型现在可以自行进行实验室实验

阿里巴巴还在物理实验室中展示了 Qwen4 代的工作情况。据阿里巴巴称，与初创公司 Deep Principle 的 Mira 系统配合使用，该模型可以自主运行 48 小时。当时，它设计、合成并测试了一种用于高性能数据中心芯片的新型冷却剂。它搜索了 270 万个候选分子，控制了一个自动化实验室，并完成了设计、合成和测量的四个完整周期。

Qwen4-Max 还与 PharmMaster 合作，PharmMaster 是北京人工智能药物发现初创公司 DP Technology 的一个平台。目标是一种针对与阿尔茨海默病相关的炎症反应的化合物。经过多轮文献综述、设计和计算，该模型优化了 24 个候选分子。据阿里巴巴称，最终候选物与目标蛋白的结合比专利中已知的起始化合物强约 3.6 倍。 DP Technology 的专家认为这一结果足以进行进一步的实验室测试。

Qwen4-Max 旨在通过单一提示构建可玩的游戏

阿里巴巴还展示了 Qwen4-Max 与 Unity、Unreal Engine 和 Godot 等成熟游戏引擎的配合。从单一的自然语言描述来看，该模型应该能够处理整个开发过程。其中包括场景设置、游戏逻辑和匹配的外部资源，以及材质、UI 和视觉效果，直到游戏可玩。

在开发过程中，模型本身运行游戏，并使用视觉和交互式反馈来调整相机工作、角色动画、命中反应和照明。阿里巴巴的示例项目是“魔法喵”，这是一款关于猫巫师的虚幻引擎冒险游戏，玩家可以在游戏中施展咒语并与一波又一波的敌人作战。据阿里巴巴介绍，Qwen4-Max还在Blender中构建3D模型，可重复用于游戏和3D打印。

Anthropic 最近将其编码助手 Claude Code 转向了相反的方向。在一波非官方的光环和侠盗猎车手：罪恶都市克隆浪潮之后，它禁止该工具重新创建现有游戏。

阿里巴巴表示，该模型编写的代码更安全，并没有提供真正的 CBRN 提升

据阿里巴巴称，在安全基准 Last Secure Code Bench 上，功能性和安全性代码的比例从 22% 上升到 31.8%。在所有三个测试级别上被评为安全的比例几乎翻了一番，从 8% 增加到 14.7%。阿里巴巴还测试了CBRN风险（化学、生物、放射性和核）。该公司表示，内部审查人员审查了该模型的完整思路。他们发现没有真正的创新能力可以显着提升用户的能力。

Qwen4-Max 可通过 QwenCloud 以及 QwenWork、Qoder 和 QwenStudio 获取。阿里巴巴计划稍后开源发布更小的 Qwen4 模型。

8 月，阿里巴巴发布了 Qwen3.8-Max，这是其首款专为运行数天的自主任务而构建的 Max 模型。它还拥有 2.4 万亿个参数，但每个代币有 950 亿个活跃参数。当时，Artificial Analysis 发现该模型每个任务需要 64 个步骤，而不是 14 个步骤，并且每个任务的成本是 Qwen3.7-Max 的两倍多。

8月下旬，阿里巴巴通过Qwen3.8-Flash-Next预览了Qwen4架构，该架构已经使用了具有510亿个参数的N-gram嵌入层。该公司于8月中旬发布了Qwen3.8-Max配重。对于 Qwen4，目前只有较小的型号才会获得开放配重。

Moonshot AI 紧随其后的是 10 月份推出的 Kimi K3.1 Pro。它有 2.8 万亿个参数，甚至更大，Moonshot 表示它在 Terminal-Bench 4.0 上仅落后于 Claude Opus 5.5。与阿里巴巴一样，DeepSeek 在 V4-Pro 中使用了稀疏注意力的混合注意力设计，以更便宜的方式处理长上下文。智浦AI则走了一条不同的路线，GLM-5.3的收获完全来自于额外的后期训练。

🤖 雷达专属 AI 研判与技术透视

Qwen4-Max的架构优化反映出头部厂商正在从单纯堆砌参数转向追求‘单位推理成本的边际效用最大化’。通过压缩上下文状态而非简单的全局注意力，阿里正在试图建立一套适配Agent复杂长链路任务的低成本算力基准，这将对追求高性价比的企业级AI部署产生直接的市场分流效应。
